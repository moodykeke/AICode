## 一、触屏手势收敛（`gestures-r46.js`）

以前同一根手指有六种含义，而且"按在脸上拖动＝转头"与"快划＝起浪"抢同一个动作——手机上按在脸上划，永远只转头、起不了浪；
"按住慢放"又和"长按开卡"叠在一起。现在触屏只有四种：

| 手势 | 做什么 |
| --- | --- |
| 轻触 | 打招呼（点头、眨眼，顺手转一圈） |
| 长按 | 开卡片 |
| 单指划 | 起浪：按在脸上划也一样，一动超过 12px 就放下这张脸；手机上 300–620px/s 的慢一些的划也算（鼠标仍是 >620） |
| 双指 | 转头：两指左右挪＝转、上下挪＝点头；落在谁身上转谁；双指时不会误开卡片 |

"按住慢放"在触屏上取消（鼠标保留）。首次提示改为"轻触打招呼 · 长按看卡片 · 划一下起浪 · 两指转头"。只处理 `pointerType === 'touch'`。

## 二、按设备的默认网格（`studio.js`）

| 设备 | 默认 | 实测每张脸 |
| --- | --- | --- |
| 竖屏手机（窄边 <520） | 4×6 | 26px（390×844，底栏占 58px） |
| 横屏手机 | 6×3 | 34px（844×390；r45 时是 21px） |
| 竖放平板（触屏、窄边 <1100） | 5×6 | 36px（768×1024） |
| 横放平板与桌面 | 7×5 | 38px |

同样只影响从没选过网格的访客。

**横屏手机**：原底栏在横屏时有 143px 高（舞台只剩 247px）。现在横屏收起底栏，快捷键改成右侧一条 62px 竖栏，舞台 390px 满高。

**"工具"键**：r45 手机上收起原底栏后，工具栏的开关把手也跟着看不见了（语言、场景、画材与设置、保存都在工具栏里，手机上够不着）。
底部第五键由"设置"改为"工具"：点一下浮出工具栏，再点收起（设置在工具栏的"画材"里）。

## 三、省电模式（`power-a11y-r46.js`）

设置 → 省电模式：**自动** / 开 / 关。

- 开：舞台 1 倍分辨率；约 30 帧/秒；没人碰、也没有动作在演（没有粒子、没有转圈、没有合奏/生态缸/合影）时降到约 12 帧/秒。
- 自动：电池低于 25% 且没在充电（Battery API），或系统"省流量"打开时自动开。r43 的弱机降分辨率照常叠加。
- 实测（headless，同一台机器）：平时 13 帧/秒 → 省电且闲置 4.5 帧/秒（约 1/3）→ 指针一动回到 12.5 帧/秒；DPR 1。

## 四、无障碍

- **舞台说明**：画布是 `role="img"`，说明随阵容更新："舞台：7×5，35 位角色：人类 3、猫 3、老虎 3……。方向键在脸之间移动，Enter 打开卡片。"
- **提示可被读屏听到**：所有 toast 同步进一个隐藏的 `aria-live` 区域。
- **键盘走到舞台**：舞台进入 Tab 顺序；方向键在脸之间移动一个红色虚线焦点圈（头也跟着看过去），读屏读出"名字 · 物种"；Enter 打开这张脸的卡片；空格照旧"看镜头"。
- 浮层工具栏的淡入淡出在"减少动态效果"时关闭。

## 五、构建审计（`node build.cjs --verify`）

在补丁契约之外新增两项，任何一项不为 0 都会让 `--verify` 失败：

- **词条审计**：扫描全部扩展，`uiText('中文')` 用到的每个中文字面量都必须在某个中英对里登记过（否则英文界面仍显示中文）。当前 0 条。
  （验证过：临时加一行 `uiText('测试未登记词')`，`--verify` 报出并失败。）
- **键位审计**：扩展里 `KEYMAP['k'] = 'fx'` 的直接赋值，同一个键被赋成两个不同动作即冲突。当前 0 条。

运行时另有 `__keys.audit()`（含各扩展自挂的键）与 `__packs.audit()`。
