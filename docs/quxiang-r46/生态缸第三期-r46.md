# r46：生态缸第三期——时间倒带、食物链与共生、进化延时、海报送展墙

2026-09-24。实现：`趣像/evolve-more-r46.js`（另在 `evolve-r44.js` 加了"共生/吃饱"的繁殖与寿命加成）。样张：`样张/41-生态缸第三期.png`。

## 一、时间倒带

- 每过一代存一份缸码（最近 80 代，每份约 600 字符，合计不到 50KB）。
- **点种群曲线上任一处**，缸回到那一代，从那里分叉重来：种群曲线、物种志、延时帧都裁到那一代；物种志记一笔"⟲ 时间倒回第 7 代（从第 42 代）。从这里分叉重来。"
- 挑战进行中也能倒带（挑战进度按代数算，倒回去等于多给自己几代）。

## 二、食物链与共生

每一代开始时先结算"谁挨着谁"：

| 关系 | 规则 |
| --- | --- |
| 捕食 | 狐狸 → 小鸡、兔子；猫头鹰 → 老鼠；猫 → 老鼠；老虎 → 小猪。捕食者挨着猎物时，22% 的机会抓走一只（每代全缸最多两起）；捕食者吃饱了，这一代多生 |
| 共生 | 人和狗（看家护院）、人和猫（捉老鼠）、小猪和小鸡（农家院）、机器人和外星访客（技术交流）。挨着时两边繁殖 +0.2、死亡 −0.05 |

按"头"（skull 基因座）算物种，所以狐耳人不算狐狸，但狐头猫耳的算。神话角色不参与。
物种志："橘·狐狸抓走了一只灰·兔子。""共生：人类和猫挨在一起就过得更好（捉老鼠）。"（同一种关系第一次必记，之后偶尔记，免得刷屏。）

实测 40 代（狐、鸡、兔、人、狗、鼠、猫头鹰、猫开局）：狐狸、猫头鹰、猫各有捕食记录，人和猫、人和狗的共生被记下；鼠和鸡被压住，人与狐的混血（狐耳人、阔嘴人）占了上风。

## 三、进化延时

- 每代存一张 360px 宽的小缩略图（JPEG，最近 150 代）。
- "延时"按钮：逐帧（8 帧/秒）画出舞台 + 代数 + 气候与只数 + 一条逐帧长出来的种群曲线，用浏览器录像（WebM/MP4）导出下载。
- 浏览器不支持录像时，改存一张"进化连环画"（最多 24 格，每格标代数）。
- 实测：7 代 → 1.1 秒 WebM，52KB。

## 四、海报送展墙

"送展墙"按钮：把进化史海报（720 宽 JPEG）投到校园作品墙，走与卡片"送去展墙"同一条平台通道
（`/api/v1/projects/{用户}/…`，`project_metadata.kind = 'quxiang-tank'`）。作品码存的是 `tank=qxt1_…`：
展墙上点开，就是这一缸（`#tank=` 链接与代码框都认）。未登录只提示"登录后可以挂到展墙"。

## 五、缸码的其他入口与"来历"

- 主界面的代码框里粘贴缸码（或带 `#tank=` 的整条链接）也能直接打开这一缸。
- 从缸码来的生物，卡片上写"来自分享的缸码 · 第 7 代 · 温和"。
