# r43（2026-09-24）：人像重绘 · 性能 · 界面与键位 · 趣味合奏与大合影

基线：r42（`docs/quxiang-r42/`）。源码 `趣像/`，产物 `static/fun/quxiang/index.html`（720KB → 844KB）。

## 一、人像重绘（35 位）—— 见《角色重绘-r43.md》

- r19 新增十一位全部重画（此前是同一个参数化模板：同脸、同刘海、兽类贴猪鼻块、道具悬空）；山海三位回到异兽画法。
- 欧洲与希腊神话九位全部重画：各按神话里最能认出的形象（山怪长鼻与小松树、冰晶王冠、托天的阿特拉斯、七条蛇发、torc 项圈、乌翼盔与发辫、橡枝为发、排箫与挤眼、牛首铜环）。
- 西游原四位加招牌；葫芦七兄弟同一家人、各自神情；r19 葫芦标记改为前后两层，不再横穿眉眼。
- 新角色做借体时有遗传标志（此前卡背"借来：undefined"）。
- 编号、名称、NATURAL 顺序不变，旧分享码仍指向同一角色。

## 二、性能与内存 —— 见《性能与内存-r43.md》

- 半身像位图缓存（`portrait-sprite.js`）：每帧只重画眼睛；4 倍降速下欧洲舞台 110 → 38ms/帧、西游 98 → 33ms/帧；缓存 ≤3MB（实测 0.5MB）。
- 细节分级：舞台尺寸下跳过 1–2px 的装饰。
- 弱机降分辨率：持续 >34ms/帧时逐级降 DPR（最低 1 倍）。手机默认 4×6。

## 三、界面与键位 —— 见《界面与键位-高观点改造方案-r43.md》

- 修 U 键冲突（工具栏 ↔ 下雨）：工具栏改 Tab（焦点进工具栏，Esc 收起）。
- 修词条索引：151 条后加词条从没生效 → 0。
- 键位表分区（合奏 / 拍照 / 音乐 / 趣味）、补 `|`、`< > |` 点键帽可触发。
- 手机：键位表变带名字的动作面板；底栏一行（185 → 57px）；语言切换回到屏内。
- 提出 P1–P3 改造方案：统一键位登记与上下文栈、工具栏浮层化（开关不再挤压舞台）、手机底部四键 + 动作抽屉、手势收敛、词条自动审计。
