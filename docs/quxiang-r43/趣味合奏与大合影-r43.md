# r43：趣味合奏与大合影效果

2026-09-24。新增四个合奏、三种合影队形、五种拍照瞬间、倒数与三种相框。实现集中在 `趣像/fun-r43.js`（构建顺序最后）。
样张：`样张/32-趣味合奏.png`（舞台实拍）、`样张/33-大合影新效果.png`（实拍成片）。

## 一、四个新合奏

| 合奏 | 玩法 | 实现要点 |
| --- | --- | --- |
| 追萤火虫 | 天色暗下来，一只萤火虫在舞台上乱飞，全场的眼睛跟着它、头轻轻歪向它；飞近谁，谁就笑一下并响一声；最后落在某位的鼻尖上，那位对眼看它——阿嚏！萤火虫被喷飞 | 每张脸挂一个 `ffWatch`（`gaze` 通道，不与其他动作抢位），逐帧按萤火虫位置算 yaw/pitch/视线；平面半身像转头只是水平压缩，所以视线放大 1.8 倍并加歪头前倾；路径是两组正弦叠加，落鼻前 3.4 秒转为"进场"；暮色 + 发光用 `lighter` 叠加 |
| 传悄悄话 | 一句话沿着相邻两排（蛇形）一个传一个，每传一次就走样一点；最后一位大声喊出来，全场笑翻，发起人一脸"我说的是××"。传到"拍照啦，茄子！"那一句时，**真的拍一张合影** | 6 组中文、3 组英文走样链（葫芦娃 → 呼噜哇 → 打呼噜！、老师来了 → 老虎开会啦！…）；说话者侧身凑近、听者侧耳，气泡画在舞台上 |
| 广场舞 | 112 拍/分，四段舞步：左右踏步（隔行镜像）→ 跳拍 → 甩头波浪（按列错相）→ 扭腰跳；第 8 拍眨眼；配鼓点、低音、五声旋律和三束彩色追光 | 一个 `squareDance` 动作内按拍号切段；音乐用既有 `tone`/`SFX.tom` 排程；追光是正片叠底的径向渐变 |
| 躲猫猫 | 全场一起缩没了，再一个个冒出来喊"哇！在这！找到我啦"；总有一个最后才探头："还有我…" | `pop` 缩到 0 再回弹；每位出现时间随机，"最后一个"固定在 93% |

入口（不占键位——键盘已按区用满，见《界面与键位-高观点改造方案-r43.md》）：
表演条"更多动作 → 趣味"、键位表新增"趣味"一排（✦ … ♫ ☺ 四个键帽，点按即演）、手机动作面板同一排。
全部有限时长、结束回位；"减少动态效果"时幅度收到约 1/3。

## 二、大合影

### 1. 队形 +3（设置 → 合影样式；"每次随机"也会抽到）

| 队形 | 摆法 |
| --- | --- |
| 心形 | 心形线按弧长均分；人多时外圈约 70%、内圈一颗小心 |
| 叠罗汉 | 金字塔：自上而下 1、2、3…，下排压住上排的肩 |
| 向日葵 | 黄金角（137.5°）螺旋：中心最大、往外渐小 |

### 2. 3·2·1·茄子（设置 → 倒数：开 / 直接拍）

快门推后 1.7 秒，屏幕中央依次浮出 3、2、1、茄子！（DOM 浮层，不进照片）。快门前 0.7 秒，全场转向镜头、睁眼、露出笑脸——
原来的合影里常有人侧着脸或正好眨眼，现在基本都正对镜头。

### 3. 拍照瞬间（设置 → 拍照瞬间：每次随机 / 不加 / 五选一）

| 瞬间 | 效果 |
| --- | --- |
| 跳跳照 | 全员在快门那一刻腾空到最高点（高度、歪头各不同，脖子跟着伸），脚下留影子 |
| 抛帽 | 毕业帽从每个人头顶抛起，快门时正好在最高点（按真实时间解算：T=0.75s 升 1.5–2 个头高） |
| 礼花 | 两侧同时喷出彩纸 |
| 抢镜 | 有一位冲到前排角上、放大、做鬼脸（吐舌、挤眉），还配一声"噗"；拍完放回原位 |
| 有人闭眼 | 一两位正好闭眼；暗房弹出后提示"有人闭眼了——按 R 重拍？" |

照片裁切框会为跳跳照、抛帽自动留出上方空间。班级人像模式只用抛帽/礼花（不动同学的脸）。

### 4. 相框 +3（暗房里 1–7 直选）

| 相框 | 样子 |
| --- | --- |
| 年画 | 朱红底、双金线、上方"××· 阖家欢"、两侧祥云、四角菱形"福"（上两个倒福）、下方"吉祥如意 · N 位 · 日期" |
| 趣像日报 | 报头、期号日期、**按拍照瞬间换标题**（"全员腾空！42 位同时起跳""毕业啦！帽子满天飞""惊现抢镜者！""有人闭眼了，本报记者表示很无奈"…）、黑白照片、"▲ 本报记者 摄"、两栏正文 |
| 卷轴 | 青瓷色绫子（斜纹）、天头题"趣像雅集 · 二〇二六年"、两条惊燕、白宣衬纸、朱印、上下轴杆与轴头 |

## 三、实测

| 项 | 结果 |
| --- | --- |
| 四个合奏 | 逐个触发并在关键时刻截图：萤火虫落鼻、悄悄话走样与喊出、广场舞追光、躲猫猫冒头；无控制台错误 |
| 队形 × 瞬间 | 心形 × 跳跳照、叠罗汉 × 抛帽、三排 × 抛帽、向日葵 × 礼花、三排 × 抢镜、圆弧 × 有人闭眼：暗房均正常弹出，成片含对应效果 |
| 相框 | 年画、趣像日报、卷轴均能导出；暗房缩略图 7 张；1–7 直选 |
| 倒数 | 3 → 2 → 1 → 茄子！逐个淡入淡出；不进成片 |
| 性能 | 这些效果只在触发期间画；平时 `drawGrid` 包装直接返回。大合影全程关掉位图缓存（成片要全细节） |
