## 二、准则：经典头像的语法（这次所有重绘都按它检验）

以"经典半身像"（上游 Head Cases 的人与动物）为尺度：

1. **一条完整轮廓**：头是一块干净的形，耳、角、冠长在头骨上，不是贴在外面的零件。
2. **五官长在脸上**：兽吻是脸的一部分（像经典狐狸、老虎的白色吻部），不是一块贴片；眼睛点睛有高光。
3. **一两个身份符号**：每位只放最能认出他的一两样东西，放大、放准；其余靠脸型与神态。
4. **半身托**：人物用统一的宽肩半身托（交领 / 和服右衽 / 赤膊 / 披肩等按角色换）；异兽用自己的躯干、前爪或盘身，站在云台上。
5. **先看小图**：先在 7×5 舞台（每格约 40–60px）上认得出，再看卡片大图的细节。

"风格百变"体现在：脸型（方、长、圆、心形、兽首）、眼型（兽眼、丹凤、圆睁白眼、竖瞳、直目）、
发式（高髻、齐刘海、光头小髻、长直发、蛇发、枝叶发）、配色与服饰文化（中、日、北欧、希腊、凯尔特）各不相同，
但都遵守上面五条，所以放在一起仍是一套。

## 五、实现与约定（供后续加角色）

- `new-faces.js`：共用零件（`folkBustCore` 半身托、`artEyeRound/Almond/White/Slit/Vertical` 五种眼、`artFlame`、`artSnow`、`artStrip`、`artBow`）
  \+ 十一位逐个构图（`FACE_ART[kind]`）+ 西游原四位（`JOURNEY_ART`）+ 葫芦七兄弟神情（`GOURD_FACE`）。
- `myth-faces.js`：欧洲与希腊九位（`MYTH_ART[kind]`、配色 `MYTH_LOOK`、特征 `MYTH_TRAITS`、遗传标志）。
- **加角色的约定改为"共用零件、逐个构图"**：r19 的纯数据驱动（`look` 字段）会把人都画成同一张脸，已停用。
  新角色写一个 `FACE_ART[kind]` 函数，用上面的零件；`folkAdd(key,…, support)` 登记，`support` 为 `'bust'`（人物）或 `'beast'`（异兽，自带云台）。
- 眼睛必须用 `artEye*` 或原有 `folkPortraitEyes/naturalEyes/atlasEye`：位图缓存靠它们登记眼睛、逐帧重画视线与眨眼（见《性能与内存-r43.md》）。
- 仅在卡片/导出分辨率才看得见的细节（卷毛、鳞纹、羽脉、念珠点）放在 `if (ART_D)` 里。
