# 趣像界面与键位：深入检查与高观点改造方案（r43）

2026-09-24。本文先给证据（真实浏览器实测），再给原则与目标形态，最后给分期路线与验收指标。
第四节列出 r43 已经落地的部分；其余为提案，待确认后分批实施。

---

## 一、诊断：26 批迭代之后，界面长成了什么样

### 1. 三套入口并存，同一件事有三四个名字

| 功能 | 工具栏 | 底栏 | 键盘 / 键位表 | 其他 |
| --- | --- | --- | --- | --- |
| 看所有动作 | — | 快捷键一览 / 动作表 | `?` `/` | 帮助面板标题"快捷键一览" |
| 画风与设置 | 风格预设、✎ 画材 | 画材与设置 | `,` | 设置面板 5 层 41 项 |
| 选角 | ＋ 角色 | — | `8` 阵容 | 头像与混生工作台 |
| 保存 | ↓ 保存 | — | — | "留下这一刻"、暗房"保存" |

工具栏展开时同屏可见 **55 个控件**（顶栏 19 + 表演条 25 + 底栏 11）。新用户看到的是控件墙，不是剧场。

### 2. 显示/隐藏会把舞台"挤一下"

工具栏展开不是浮在舞台上，而是参与排版：**桌面舞台高 706 → 611px，每张脸 73 → 64px 并整体下移**；
手机上舞台少掉 24% 的高度。每次开关工具都是一次全场缩放，破坏"剧场"的连续感。
把手的位置还有三种模式（底栏 / 右上角 / 隐藏），隐藏时只能靠键盘叫回。

### 3. 键位没有中心登记，冲突靠事后发现

- 基线 `KEYMAP` 已占满 26 个字母与 0–9；之后的键全是各扩展"就近"加的：r22 `[ ] \ { } |`、r27 `Shift+− / Shift+=`、
  r29 `~`（与 `` ` `` 说话同键，r30 改 `;`）、r31 `; '`（`;` 同时触发合照与全场弹奏，"全班长出长脖子"）、`< >`。
- **五个扩展自己挂 `keydown` 监听**（studio、scale-play、group-photo、photo-lab、bigscreen/class），不经过 `KEYMAP`：
  帮助面板看不见、点键帽不触发、冲突检查查不到。
- **本轮又查出一处真冲突：`U` 同时是基线"下雨"和工具栏开关**——按 U 叫出工具栏的同时全场下雨。
- 键位表里扩展键的名字在中文界面显示英文（Strum the cast、Giggle wave、Group photo…），`< >` 点了没反应。

### 4. 手机端：沿用了桌面的隐喻

实测 390×844：
- 默认 7×5，每张脸约 45px，轻触、长按都点不准；
- 键位表把键帽缩成一排字母、**隐藏了全部名字**——手机上它是唯一的动作入口，却看不出每个键是什么；
- 底栏四个工具按钮竖排，底栏高 185px；"显示工具"把手**压在"5 星河"键帽上**；终章图例被截断；
- 顶栏第一行向左溢出，**语言切换被挤到屏幕外（x = −133）**，手指够不到；
- 手势过载：轻触 = 打招呼、快划 = 浪、慢划 = 涟漪、按住 = 慢放、再久 = 开卡、拖动 = 转头，同一根手指六种含义；
  首次提示还写着"盯着谁，谁会注意到你"——触屏没有悬停。

### 5. 国际化：一半新词条从没生效

`UI_INDEX` 只在 `locale-lookbook.js` 载入时建一次，之后 14 个扩展 push 的 **151 条（占全部 603 条的 25%）从没进索引**：
英文界面下班级人像、暗房、大屏、合奏动作仍是中文；中文界面下键位表里是英文。r41 的"词条收口"补的 45 条也在其中。

### 6. 性能：默认首屏最重

见《性能与内存-r43.md》。各系列半身像已靠缓存降到原来的约 1/3；默认首屏的经典半身像（3D 头）仍是逐帧最贵的场景。

## 二、原则

1. **舞台优先**：任何界面都不改变舞台几何。工具是浮层，不是排版的一部分。
2. **一处登记，处处生成**：动作、键位、名字（中英）、分区、可用场景只登记一次；键位表、手机动作面板、表演条菜单、帮助文案都从登记表生成。
3. **键位按区，而不是按先来后到**：键盘是有地理的，每个区一种语义，新功能进区，不再"找个没人用的符号"。
4. **上下文分层**：舞台 / 卡片 / 暗房 / 大屏 / 帮助 / 设置各是一层，按键只交给最上层；弹层开着时舞台一律不接键（暗房已这样做，推广到全部）。
5. **手机不是小桌面**：没有键盘、没有悬停；动作入口是面板，不是键帽；手势每种只有一个含义。
6. **可测的界面**：冲突、词条覆盖、控件尺寸、舞台是否被挤，都进 `build.cjs --verify` 与回归套件。

## 三、目标形态

### 3.1 键位地图（区 → 语义）

| 区 | 键 | 语义 | 说明 |
| --- | --- | --- | --- |
| 数字排 | `1`–`7` | 终章 | 保持 |
| 数字排右 | `8 9 0 − =`（Shift：`_ +`） | 舞台设置：阵容、彩色、声音、列、行 | 保持 |
| 字母区 | `A`–`Z` | 单人动作；Shift = 全场版；按住空格或 Alt = 刷到脸上 | 保持上游肌肉记忆 |
| 空格 | `Space` | 看镜头 | 保持 |
| 括号区 | `[ ] \ { }` | 合奏 | 已满；新合奏进"更多"面板，不再抢键 |
| 引号区 | `; '` | 拍照：合影 / 看照片 | 保持 |
| 尖括号区 | `< > \|` | 音乐：弹一遍 / 换调式 / 换一首 | 保持 |
| 系统 | `, . / ?` `` ` `` | 设置、收藏、帮助、说话 | 保持 |
| 界面 | `Tab`（r43） | 显示/收起工具栏，焦点进入工具栏 | 替代 U |
| 通用 | `Esc` / `Enter` / `Ctrl+Z` | 退出一层 / 打开指着的卡片 / 撤销 | 统一语义：Esc 永远只退一层 |

### 3.2 统一键位登记（提案 P1）

```js
QX_KEYS.register({ key: '<', zone: 'music', ctx: 'stage', zh: '全场弹一遍', en: 'Strum the cast', run: strum });
```

- 所有扩展改用登记，不再各挂 `keydown`；一个总分发器按上下文栈把键交给最上层。
- `build.cjs --verify` 增加：同一上下文内重复登记 = 失败；登记了但没有中文或英文名 = 失败。
- 键位表、手机动作面板、表演条"更多动作"、帮助文案全部由登记表生成——不会再有"有键没名""有名点不动"。

### 3.3 工具栏：浮层化（提案 P1）

- 顶栏与表演条改为舞台上方的半透明浮层（`position:fixed` + 背景模糊），**展开不再改变舞台尺寸**；
- 空闲 6 秒自动淡出（指针移到顶部 48px 内或按 Tab 再出现）；
- 三行合一：品牌 · 场景 · 舞台摘要 · 角色 · 画材 · 保存 · 更多（其余进"更多"抽屉）；目标同屏控件 ≤ 15 个。

### 3.4 手机：底部动作面板（提案 P1–P2）

- 底栏只留四个按钮：**演**（动作面板）· **拍**（合影）· **角色** · **设置**；
- "演"打开底部抽屉，分页：动作 / 终章 / 合奏 / 音乐 / 拍照，每格图标 + 名字（r43 已先把键位表变成带名字的分区面板，作为过渡）；
- 手势收敛为四种：轻触 = 打招呼，长按 = 卡片，单指快划 = 浪，双指 = 转头；"按住慢放"改到面板里的开关；
- 横屏与平板单独给默认网格（横屏 7×4、平板 6×5）。

### 3.5 国际化（提案 P2）

- 词条与键位一起登记（见 3.2）；
- `--verify` 扫描扩展源码里面向用户的中文字面量，未登记即报错（r41 手工做过一次，应自动化）。

## 四、r43 已落地

| 项 | 做法 | 验证 |
| --- | --- | --- |
| U 键冲突 | 工具栏改 Tab：舞台上按 Tab 展开并把焦点交给第一个按钮，从工具栏按 Esc 收起、焦点还给舞台；U 只下雨；把手与设置里的"按 U"改为"按 Tab" | 实测：U → 只下雨；Tab → 展开、焦点在按钮；Esc → 收起 |
| 词条索引 | 全部扩展之后重建索引，并让之后的 push 自动入索引 | 未入索引 151 → 0；"大合照（;）→ Group photo (;)"、"Giggle wave → 笑场"等双向生效 |
| 键位表分区 | 合奏 / 拍照 / 音乐三排加区名；补 `\|`（换一首）；加一行"Tab · Esc · Enter"说明 | 中文界面扩展键全部中文名 |
| 键帽点不动 | `< > \|` 点键帽时把按键回放给 scale-play 的监听 | 实测点 `>` 调式由 gong 变为 zhi |
| 手机键位表 | ≤640px 变为四列、带名字、分区标题的动作面板，可纵向滚动 | 样张 28 |
| 手机底栏 | 一行横滑：把手 → 动作表 / 设置 / 收藏 / 声音 → 终章；不再竖排、不再重叠；右缘渐隐提示可滑 | 底栏 185px → 57px |
| 手机顶栏 | 语言切换回到屏幕内 | x −133 → 12 |
| 手机网格 | 竖屏手机默认 4×6（仅限没选过网格的访客） | 脸约大一倍、每帧少画 31% |
| 触屏提示 | 首次提示改为触屏真正做得到的手势（长按看卡片） | — |
| 弱机 | 位图缓存、细节分级、持续掉帧时降分辨率 | 见《性能与内存-r43.md》 |

## 五、分期路线与验收指标

| 期 | 内容 | 验收 |
| --- | --- | --- |
| P0（r43，已完成） | 上表 | 冲突 0；词条未索引 0；手机底栏 ≤ 60px；系列场景 4 倍降速下每帧 ≤ 40ms |
| P1 | 统一键位登记 + 上下文栈；工具栏浮层化；手机底部四键 + 动作抽屉 | 开关工具舞台尺寸变化 = 0；同屏控件 ≤ 15；键位表 = 登记表 100% |

| P3 | 经典半身像按转角分档缓存或静止帧跳画；设置里显式"省电模式"；无障碍（焦点顺序、读屏标签、减少动态效果全覆盖） | 默认首屏 4 倍降速每帧 ≤ 50ms；键盘可达全部功能 |
