## 一、大合影（`photo-r49.js`）
### 修复：连续点"大合照"人物越来越小
- 原因：新照片按"当前的头"定尺寸，而上一张的队形还没散（头已缩小），一次次叠下去。
- 现在：①拍摄中（含入场动态）再按不响应；②所有队形一律按"回到格子里时的尺寸"算；③表演条菜单里的"大合照"按钮以前直接绑着最早的函数（绕过倒数与拍照瞬间），改为走完整流程。
- 实测：连按 4 次 + 3 轮"拍中再按"，平均头尺寸 38.4 → 38.4。

### 合影设置（新面板）
入口：表演条"更多动作 → 合影 → ⚙ 合影设置"、暗房里的"⚙ 合影设置"、手机底栏长按"拍"。同样的选项也在设置面板"合影"组。
选项：合影样式 · 入场动态 · 拍照瞬间 · **烟花（随机 / 开 / 关）** · 倒数 · 相框，选完直接"拍一张"。

### 入场动态（摆队形前先闹约 2 秒）
| 动态 | 样子 |
| --- | --- |
| 追赶 | 排成一串绕舞台跑圈，一个追一个，边跑边蹦 |
| 乱跑 | 各自冲向两个随机的地方，忽大忽小、东倒西歪 |
| 跳跳 | 原地连跳（起跳拉长、落地压扁），边跳边往中间凑 |
| 忽大忽小 | 一波一波缩小又鼓起 |
| 人浪 | 从左到右掀起两道人浪 |
配跑步的踢踏声、弹簧声；"减少动态效果"时幅度收小、时长缩短。

### 新队形（共 12 种）
自拍（一位举着"手机"凑到镜头前、其余挤在后面探头）· 靠头（挤成一团、头都歪向中间）· 高矮排（从小到大、脚底对齐）· C 位（中间最大、两边渐小的 V 字）· 阶梯（一排比一排高、往右错开）。

### 烟花
快门前几百毫秒升空，快门那一刻正好在头顶绽开；画在人物**后面**，成片往上多留一截把烟花框进去；带爆裂和噼啪声。

## 二、葫芦七子重画（`gourd-r49.js`）
- 以前七兄弟共用一张脸形、同一发型、同一顶叶冠，只靠小标记区分。现在改成 Q 版大头（头约占全身六成），每人从脸形、发型、眉眼、嘴、配饰到周身小物都不同，只保留胸前同色的小葫芦扣与叶子领：
  小火（火苗竖发、浓眉虎牙、身边火星）· 小山（平头方脸、一字粗眉、石子耳坠）· 小风（飞扬发梢、挤眼吹哨、风带）· 小叶（锅盖头嫩芽、弯弯笑眼、雀斑）· 小潮（浪花刘海、水汪汪大眼、水珠）· 小雾（长刘海遮眼、月牙发夹、整个人淡一点）· 小灯（双丸子星簪、星星眼、头光）。
- "国风葫芦"不再单独成一类：场景按钮与角色包里去掉，七兄弟归入"动画来客"；旧分享码仍能打开。

## 三、半身像头肩分离（`bust-split-r49.js`）
- 反馈：欧洲神话人物点一下，整个人连肩膀一起往上跳，脖子也伸长。原因：这些角色是整张半身画，舞台把"头的位移"套在整张画上。
- 现在有肩膀的半身像（西游、百鬼、欧洲神话、葫芦七子、动画来客）在位移明显时分三层：肩膀钉在原地、脖子按同物种肤色补一段、头带位移；半身像的弹跳高度收到 55%。兽类、海洋、花园角色仍整只跳。
