## 二、代码侧四处缺口

1. **名牌设置不即时生效**：班级卡原来把"相框 + 名牌"烤进画布，改设置要重新载入班级才生效。
   改为**只烤人像**（200×250），相框与名牌**每帧矢量绘制** —— 设置改了立刻生效，字在任意缩放下都清晰，
   卡内存 11.1MB → **9.9MB**（52 张，−11%）。
2. **帮助表缺 `<` / `>`**（全场弹一遍 / 换调式）：已补进键位表，手机端点键帽即可触发。
3. **未登录的提示词不准确**：原来无论什么情况都说"没找到你名下的班级，教师可从全校班级里选"。
   现在按角色分开：教师说"你名下暂时没有班级…"，非教师说"没找到你名下的班级；**登录后才会显示你的班**"。
4. **画布归属漏标**：卡片正反面画布在审计里显示"未标记"（只有开过卡片才会被标）→ 启动即标，
   以后审计不会再出现来路不明的大画布。
