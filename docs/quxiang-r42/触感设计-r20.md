# r20：触感设计——把"看"变成"摸得到"

2026-09-23。指针（手指）不再只是光标，而是一盏提灯、一阵风、一颗投进水里的石子。
六个动作各自独立，都与既有交互（拖动转身、长按开卡、双击收藏、动作键、演奏）互不干扰。

## 六个动作

| 手势 | 发生了什么 | 设计意图 |
| --- | --- | --- |
| 移入 | **提灯**：一团会呼吸的暖光跟着指针，走到哪儿把哪儿照亮 | 舞台变成一间暗房，看谁由你决定；纸色越深越明显 |
| 轻触 | **打招呼**：眨眼＋笑一下＋轻轻颔首；害羞的会脸红，火爆的会皱眉 | 一声轻响（合成的短拨弦）＋极轻震动，像碰了一下谁的肩 |
| 快划 | **风过麦田**：一串角色顺着划动方向依次倾倒再弹回，身后留一道风痕 | 手感是"掠过"，越快要越明显（阈值 620px/s 起风） |
| 慢划 | **水面涟漪**：一路落下扁椭圆的水纹，波纹扫到谁，谁颔首一次 | 手感是"在水里拖手指"；与快划互斥，快慢自然分流 |
| 凝视 | **被注意到**：指针停在同一张脸上约 2.6 秒，它抬眼、浮出一个小符号（♥ ✦ ♪ ?）并轻响一声 | 你看它，它也看你；每位角色 12 秒内只回应一次，不腻 |
| 按住 | **慢下来**：这一位的时间减半（呼吸变深、闭嘴屏息），整台戏也一起放缓到 0.42×，松开缓缓回到常速 | 最解压的一下；按久成开卡时直接归位，不留残影 |

## 手感参数（可调）

- 倾倒：弹簧 k=30、阻尼 5.4；冲量按距离衰减 `(1-d/reach)^1.6`，reach 随速度 150→270px。
- 涟漪：半径 190/s（慢划）或 300/s（点击），寿命 2.6s；命中带 64px；同屏最多 3 圈，间隔 460ms。
- 提灯：半径 150–184px 呼吸，alpha 0.13（`lighter` 叠加），按住时放大 1.25×。
- 凝视：静止 0.25s 起算，累计 2.6s 触发；冷却 12s。
- 慢镜头：目标 0.42×，缓动系数 6/s。

## 实现位置与约束

- 全部在 `开发与验证/touch-feel.js`（构建顺序排在最后），不改既有绘制与动作函数；
  角色偏移通过包装 `Head.prototype.update` 叠加（滚转单独记账，避免与基础回正打架），
  覆盖层通过包装 `drawGrid(dt,now)` 在其上轻铺，时间缩放只作用于传下去的那个 dt。
- 尊重设置：系统"减少动态效果"时只保留轻触回应与提灯，其余（成浪、涟漪、凝视、慢镜头）自动关闭。
- 不抢事件：笔刷（局部风）、终章（SUPER）、繁衍、开卡期间一律让位；触屏轻触/长按仍走既有判定。
- 音频走既有 `tone()/SFX/allow()`（带声像与限流），震动仅在声音开启时触发一次 8ms。
- 调试出口：`window.__feel`（状态与计数）、`window.__heads`、`window.__feelProbe(x,y)`。

## 验证（浏览器实测）

- 轻触：`__feel.pat` 升至 0.7，被点角色眨眼/微笑/颔首。
- 快划：一次划过产生 75 次冲量、9 位角色倾倒，且不产生涟漪（快慢分流正确）。
- 慢划：一次拖过产生 5 圈水纹、命中 4 位角色颔首。
- 凝视：停 3.2s 后浮起符号并响应。
- 按住：`timeScale` 0.45，松开 0.7s 内回到 0.99。
- 无控制台错误；首屏一次性提示"现在可以摸：…"，页脚常驻提示同步更新（中英各一份词条）。
