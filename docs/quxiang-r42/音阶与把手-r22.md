# r22：音阶弹跳 · 把手归位 · 缺位动画接上键盘

2026-09-23。三件事：把 42 张脸变成一件乐器；把"显示工具"从画布上请下去；把一批只会被邻居
触发的动画接上键盘。

## 一、音阶弹跳（点击角色 → 弹跳 + 一个音）

**音高分布不固定**。进入时随机抽出五件事，再按网格铺成"音阶格子"：

| 随机项 | 取值 | 作用 |
| --- | --- | --- |
| 调式 | 宫 / 商 / 角 / 徵 / 羽（五声） | 决定音级间距；五声任意组合都不难听 |
| 调 | C D E F G A 六个基准音 | 换调不换关系 |
| 偏移 | 0–4 | 同一张脸在不同场次听到不同音级 |
| 走向 | 向右升 / 向右降 | 有时左低右高，有时相反 |
| 行距 | 每往下一行走 1–3 个音级 | 决定斜向是"琶音"还是"三度和音" |
| 基八度 | 上排高、下排低（±1 八度内） | 竖着点像在爬音阶 |

于是：**横着划是一段音阶，斜着点是和弦，竖着点是八度**；每次进来（以及每次换场景）重新抽，
所以不会"每次都是那一串音"。

**指定乐曲**：曲子用**音级**记谱，不写死频率，因此换任何调式都能原样奏出。
演奏时按拍子找"当前调式里离该音级最近的那张脸"，让它弹跳——一个音一张脸，头部随乐轻摆。
内置三首：小星星 / 欢乐颂 / 茉莉花（`|` 循环，表演条里也有按钮）。另有"全场弹一遍"（`;`）。

音色复用应用自带 `SFX.marimba`（木质马林巴，与"挥手"同一件乐器），带声像与限流。

## 二、沉浸把手归位

原来"显示工具"固定在**画布顶部居中**——正好压在头像区。现在默认放进**下方栏**（页脚那一行），
设置里给三个位置：**底部栏（默认）/ 右上角 / 隐藏（按 U 叫回）**。选择随设置保存并进场景分享码。

## 三、缺位动画接上键盘（五个）

应用里有一批"反应型"动画只作为邻居反应的素材，没有键盘出口。这里把它们编成五个整场动作：

| 键 | 动作 | 内容 |
| --- | --- | --- |
| `[` | 笑场 | 一排排笑开，隔行随声点头 |
| `]` | 仰望 | 齐齐抬头看天，后排先抬、前排随后 |
| `\` | 谢幕 | 谢幕式鞠躬，从右往左依次 |
| `{` | 欢呼 | 一排接一排地欢呼 |
| `}` | 轮唱 | 一列接一列，唱成一个轮子 |

五个都写进**快捷键一览**（帮助面板新增一行键位）与页脚图例，表演条的"更多动作"里也各有一个按钮。

**注意：数字键不能用**——`1`–`7` 是终章、`Shift+数字` 也会落到终章上（实测 Shift+1 会开出"开花"终章），
所以曲目改用 `|` 循环，不碰数字。

## 设置（"设置页面要设计齐全"）

新增面板组 **演奏与界面**：
- 音阶调式：每次随机（默认）/ 宫 / 商 / 角 / 徵 / 羽
- 沉浸把手：底部栏 / 右上角 / 隐藏（按 U）

两项都进 `SHARE_KEYS`，导入别人的场景会得到同样的调式与把手位置。

## 验证（浏览器实测）

- 音阶：抽到"徵调式 · 293.66Hz · 偏移 2 · 向右升 · 行距 1"，前 12 格音级／八度分布符合设计。
- 点击角色：上抛初速 −1.32（跳起）+ 摆动计数 +1；连击有幅度上限。
- 乐曲：`|` → 小星星开始、约 6.5s 结束；再按 → 欢乐颂（进度记住）；`;` 全场依次弹过。
- 五个新键位各触发 42 张脸的动作；帮助面板出现 `[ ] \ { }` 一行。
- 把手：默认所在元素 = `#caption`（底栏）；切右上角/隐藏即时生效且 U 仍可叫回。
- 无控制台错误。
