## r21：头飞起时的脖子约束（配置项）（2026-09-23）

上一版有人指出"点击角色，头跳起来、脖子留在原地"看着像断了。查明：普通单击只让角色旋转，
真正让头飞起的是 **Heads off（F 键）终章与飞行笔刷**所用的 `float` 动作——它原本就是"头像瓶塞一样
弹起漂浮、脖子留在原地"。而 `longneck`（长脖子）与 `balloon`（气球）走的是"脖子跟着走"的做法。

于是把这件事交给一个配置项，两种做法都保留、可随时切换：

- 设置 → 动作 → **头飞起时**：`脖子跟随`（默认）／`头跳起`
- 勾"脖子跟随"：头飞起时脖子一起伸长（伸缩脖），不再有断口；换"头跳起"即回到原来的留桩效果。
- 该选择随设置保存，并进入**场景分享码**（`SHARE_KEYS` 增加了 `neckMode`），别人导入你的场景会得到同样的脖子手感。

实现：新增 `开发与验证/touch-feel.js` 之后的 `neck-mode.js`（约 40 行），只包 `FXDEF.float.step`——
按配置补 `d.neck='long'` 并清掉 `d.stump`，不动既有绘制与其它动作；另在动作组插入一个两态控件与中英词条。
调试出口 `window.__neck`（mode／panelHasItem／groups）。

实测：默认按 F → 42 位角色集体伸着脖子升起（截图核对）；切到"头跳起"→ 回到留桩漂浮；
设置写入 localStorage；无控制台错误。
## r20：触感设计——把"看"变成"摸得到"（2026-09-23）

指针（手指）成为一盏提灯、一阵风、一颗投进水里的石子。六件事，都与既有交互互不干扰：

- **提灯**：会呼吸的暖光跟着指针，走到哪儿照亮哪儿（深色纸面上尤其好看）。
- **轻触**：点一位角色——眨眼、微笑、轻轻颔首；害羞的脸红，火爆的皱眉，配一声合成的短拨弦与极轻震动。
- **快划成浪**：快速掠过（>620px/s）时，一串角色顺着方向依次倾倒再弹回，身后留一道渐隐的风痕。
- **慢划涟漪**：慢慢拖过纸面，一路落下扁椭圆水纹，波纹扫到谁，谁颔首一次（与快划按速度自然分流）。
- **凝视回应**：指针停在同一张脸上约 2.6 秒，它抬眼看你，浮出一个小符号（♥ ✦ ♪ ?）并轻响一声；每位 12 秒内只回应一次。
- **按住慢下来**：按住一位角色，它的时间减半（呼吸变深、闭嘴屏息），整台戏也放缓到 0.42×，松开缓缓归位；按久变成开卡时直接归位。

实现集中在 `开发与验证/touch-feel.js`（构建顺序最后）：不改既有绘制与动作函数，角色偏移包装
`Head.prototype.update` 叠加，覆盖层包装 `drawGrid`，时间缩放只作用于传下去的 dt。
系统"减少动态效果"时只留轻触回应与提灯；笔刷/终章/繁衍/开卡期间自动让位。
手感参数、实现约束与实测数据见《触感设计-r20.md》。

一次实测（headless Chromium）：轻触 pat 0.7；快划 75 次冲量、9 位倾倒且 0 次涟漪（快慢分流正确）；
慢划 5 圈水纹、4 位颔首；凝视 3.2s 触发；按住 timeScale 0.45 → 松开 0.7s 回到 0.99；无控制台错误。

## 构建规则

1. 只编辑 `开发与验证/baseline.html` 与扩展脚本；运行 `node build.cjs` 生成 `index.html` 和 `app-check.js`。
2. 运行 `node verify.cjs`，确认 `results.json` 中的版本、检查数量、样张清单和 `browserTested` 状态。
3. 生成 `manifest.json` 后再压缩；压缩包使用新的版本名，不替换历史包。
4. 发给其他小组的包必须同时包含 `使用说明.md`、`验证说明.md`、`版本记录.md`、`样张/` 和 `manifest.json`。

## 验收边界

当前自动检查证明绘制函数、动作边界、分享／撤销、语言和画材配置可运行；它不能替代真实浏览器中的点击、抽屉焦点、下载、音效、移动端布局和真机性能验收。发布前应在桌面浏览器完成“打开 → 7×6 舞台 → 三种编排 → 语言 → 画材 → 导出”的一遍实测，并把结果补入本页。
