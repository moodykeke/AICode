# r31：暗房（拍完先看照片）+ 键位梳理

2026-09-23。你指出的问题：**拍完照片没有任何显示，也没有保存/分享/取消**——r29 的导出接口只挂在调试出口上，
界面上根本没有入口，等于拍了就没了。这次补上暗房，并把键位重新梳理一遍。

## 一、暗房：拍完先看照片

`;` 拍完全班 → 闪光灯 → **弹出暗房**：

- **照片本体**：按队形裁切，只框住这一群人（不是整块舞台）；
- **相框随选**：下面四个小样（白框题字 / 胶片 / 宝丽来 / 原图）就是四种相框的实时预览，点哪张换哪张；
- **三个动作**：
  - **保存**：存 PNG 到下载（沿用应用的落盘通道，带"生成中"忙态）；
  - **分享**：优先系统分享（手机上直接分享到微信等）；不支持就**复制到剪贴板**；再不行存到下载并说明；
  - **取消**：关掉弹窗，照片还在——按 `'` 随时能再打开；
  - 另外给了 **重拍**：散开重摆一次造型（照片不满意时不用重来一遍流程）。

## 二、照片清楚多了

手机上舞台只有四百来像素宽，直接拷贝的成片只有 ~160px。现在**开拍时临时把舞台画布的分辨率提上去**
（长边目标约 760px，整幅不超过约 600 万像素），整个摆造型过程都在高分辨率下渲染，快门抓的就是屏幕上那一帧本身，
拍完立刻还原。成片：手机 481×434、桌面 892×796（原来 160×139 / 445×398）。

**踩过的两个坑**（都记在文档里）：
1. 一开始想"事后把这一帧重画一遍"——不行：`drawScene` 内部还会调一次 `update`，等于让角色多走一帧物理，
   脸和脖子都变了（成片上长出一片怪脖子）；
2. 提分辨率后纸纹没跟着换尺寸——`knock()` 靠 `paperFill()` 的图案按"设备像素"贴回纸面做遮挡，
   图案还是旧尺寸就只盖住半张画布，本该被挡住的身体全漏出来（成片一片灰影）。跟着 `rebuildPaper()` 就好了。

## 三、键位梳理（这次发现一处真冲突）

**`scale-play` 里"全场弹一遍/换调式"用的是 `;` 和 `'`**——而且它是自己挂的 document 键盘监听，不走 KEYMAP，
所以 r30 把合照放上 `;` 之后，**两个处理器同时触发**：一按 `;`，照片开拍的同时全场被弹了一遍
（每张脸得到一个向上冲量 ≈ −2.98），于是照片里"全班长出长脖子"。

现在：

| 键 | 作用 |
| --- | --- |
| `;`（`:`、`；`、`：` 等效） | 大合照 |
| `'`（`"`、`‘’“”` 等效） | 看照片（重开暗房） |
| `<` | 全场弹一遍（原 `;`，让开） |
| `>` | 换一种调式（原 `'`，让开） |
| `|` | 换一首曲目（未变） |

暗房里：`⏎` 保存 · `S` 分享 · `R` 重拍 · `1–4` 直选相框 · `← →` 换相框 · `Esc` 取消（弹窗内会把舞台按键吞掉，
不会误触发表演动作；按钮上直接印着对应键）。

另外两处加固：**摆造型期间不再收冲量**（弹奏/点击都不会把队形弹歪）；
**脖子跟随的触发阈值改成与头身成比例**`max(1.2, s×0.08)`——原来固定 1.2px，余震两三像素就整条脖子抽出来。
