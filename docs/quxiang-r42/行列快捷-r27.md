# r27：行/列快捷按钮（菜单里一键增减）

2026-09-23。回应两件事：默认角色数量，以及菜单里的行/列快捷按钮。

## 默认是 42

首屏默认 **7 列 × 6 行 = 42 位**（产品既定：默认先让完整群像形成舞台；舞台摘要按钮点一下就回到 7×6）。
按 r19 的决定，默认选角是经典半身像。

## 菜单里的行/列 +−

设置 → 场景与演员 → **列数 / 行数** 两行，滑块下面各多了一对 `−` `+`：

- 点一下增减 1；列数范围 3–14、行数范围 2–10（与滑块同一套边界）；
- 滑块值为 0 表示"自动"，此时从**当前生效值**起步，不会突然跳回自动；
- 改动即生效：舞台重排、人数与摘要同步刷新（复用应用既有的保存与重排路径）。

## 键盘也补齐

原本只有 `−` / `=` 调**列**；现在：

| 键 | 动作 |
| --- | --- |
| `−` / `=` | 列数 −1 / +1 |
| `Shift` + `−` / `Shift` + `=` | **行数** −1 / +1（本轮新增） |
| 点舞台摘要「舞台 · 7 × 6 · 42 位」 | 一键回到 7×6 |

新增的两个键也写进了**快捷键一览**（帮助面板），面板里的按钮标签与 aria 也都有中文（英文词条同步补了）。

## 实测

- 默认：`舞台 · 7 × 6 · 42 位`；
- 点 `增加列数`：7×6 → **8×6（48 位）**；点 `增加行数`：→ **8×7（56 位）**；点 `减少行数`：→ 8×6（48 位）✓
- 键盘：`=` → 9×6（54 位）、`−` → 8×6（48 位）、`Shift+=` → 9×6、`Shift+−` → 8×6 ✓
- 无控制台错误。
