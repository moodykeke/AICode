# r41：词条收口（新增界面文案全部入表，中英都能切）

## 机制回顾（为什么必须收口）

界面文案是**整串匹配**翻译的：画布上每帧重绘的文字（班级标题、载入面板、展板题字）用 `qxLocal` 取词，
天然双语；但 **DOM 里"只设一次"的文字**（按钮、面板标签）必须**在词条表 `UI_PAIRS` 里有登记**，
切换语言时才会被观察器改过来 —— 没登记的会留在中文。

## 本轮做了什么

1. **审计**：把各扩展里面向用户的中文串（`qxLocal('…')` 与直接 `textContent=` 两类）全量扫出来，
   与"所有 `UI_PAIRS.push` 登记过的"对比 → 找出 **45 条没登记**的（班级人像入口与面板、暗房与展板、
   大屏模式、弹奏按钮上印的键位、若干提示句）。
2. **收口**：新增 `趣像/i18n-fill.js`，把这 45 条按"整句登记"补齐（含按钮上印的键位说明，如「大合照（;）」
   →「Group photo (;)」）；拼接句仍在源头逐段 `qxLocal`（沿用既有约定）。
3. **小修**：大屏模式的情绪名英文侧统一首字母大写（Original / Joy / Anger / Sorrow / Delight）。

## 验证（同一账号、同一功能，两个语言各跑一遍）

验收就是按这个真实开关跑的。回归套件 **28/28** 通过；双网指纹一致。
