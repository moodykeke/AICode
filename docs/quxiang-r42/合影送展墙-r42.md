# r42：合影送展墙（暗房「送展墙 / W」→ 校园作品墙）

## 一、通道（与角色卡同一套，不新增后端）

- **提交**：暗房「送展墙 / W」→ `POST /api/v1/projects/{用户名}/quxiang-photo-{id}`，
  `project_type=quxiang`、缩略图=成片 JPEG(≤1.6MB，超了自动降档)、`main.txt`=合影说明（班级/日期/人数）、
  `project_metadata.kind='class-photo'`（含 className/frame/n/date）；随后置 ispublic+ispublished（自发布）。
- **展示**：作品墙（`/campus/wall`）已有 quxiang 全链（列表/灯箱/发布/撤下），合影作为一种新 kind 区分展示。

正则兼容词距与早期「· ·」双点写法）。

## 三、踩的两个坑（都修了）

1. **标题里的「·」被翻译器叠成「· ·」**：词条表里有 `['· 合影留念',' · class photo']`（带词距），
   提交时 `who + ' · ' + qxLocal('班级合影')` 的组合被 MutationObserver 按子串规则叠了一遍 →
   库里出现「八年级05班 · · 班级合影」。修：应用侧 title 不再嵌套空格词距；前端判别兼容。
2. **公开展墙卡片漏挂 is-photo**：第一次的模板替换只匹配到"我的作品"那张卡（含 is-pending 的行），
   公开墙那张没绑定 → 判别函数生效了（标题对）但样式类没挂上（不跨列）。修：补上 `:class` 绑定。
