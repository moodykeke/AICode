# v13 使用入口

看到页面标题为 v13.0.0 即为本轮版本。直接打开同目录 `index.html` 只适合查看静态文件；要体验表演、角色互动和状态更新，请使用下面的本地 HTTP 预览入口。

推荐使用本地 HTTP 预览：双击同目录的 **启动本地预览.cmd**，然后访问 `http://127.0.0.1:4173/`。如果浏览器出现 `Unsafe attempt to load URL file://...` 或点击表演无响应，说明页面仍以 `file://` 打开；关闭旧标签，改用这个本地地址即可。服务只绑定本机回环地址，关闭命令窗口即可停止。

- 点“国风葫芦”：进入七兄弟的 7 列 × 6 行舞台。
- 页面默认进入沉浸式舞台，顶部操作栏收起，只留下一个低对比度“显示工具”把手。点击把手或按 `U` 展开；再次点击“收起工具”即可恢复完整画面。这个状态只保存显示偏好，不会改角色和作品。
- 沉浸模式的“显示工具”把手始终保留在舞台顶部并可直接点击；工具栏展开后，收起入口移到右下角，避免遮挡主题与动作按钮。若把手被误错过，也可以按 `U` 切换。
- 工具栏展开后按“品牌与方向 → 主题场景 → 舞台与工具 → 表演动作”分层：主题横向滚动，舞台、角色、画材、保存保持一组，动作单独放在浅绿色动作带；中等宽度自动变成两行，小屏幕再按品牌、工具、主题顺序折叠，避免按钮挤成无意义的长条。
- 点“更多主题”：选择“西游行旅”“山海异兽”“百鬼小町”（日本妖怪）或“欧洲神话人物”。欧洲册包含巨人、神祇、妖灵与英雄，角色按同一套头像版式成册，不掺入其他册。
- 点“经典半身像”：查看原有带肩身的人物与动物；潮间带和其他自然主题也独立展示。
- 点“＋ 角色”：单选同一角色，或跨册混选。混选采用系列分区，系列内部固定顺序轮排；不会自动把身体混合。选择超过 48 类会自动改用 64 位。
- 角色库每个类别标题都支持“全选／全不选”和“收起／展开”；全选一组会自动切换到混选，标题右侧的 `已选／总数` 用来确认当前组是否完整纳入。
- 要主动创作混生形象，在角色库下方选择主体与借来的结构。新角色可借入叶冠、杖、翼、伞冠或冰棱。
- “欧洲神话人物”现在是大脸、短颈、低肩托的头像册：保留苔岩特洛尔、约顿·霜冠、阿特拉斯·云穹三位巨人，同时加入美杜莎、塞尔努诺斯、瓦尔基里、德律阿得、法翁与米诺陶；每位角色用脸型、眉骨、眼裂、鼻梁与头部符号区分。
- 角色卡中的“繁衍”仍按两步进行：先打开一张卡，再点另一位角色。后代保留一个主体物种，同时记录另一位的结构标签；例如大娃 × 二娃会显示混生名称，并把第二位的叶冠、盾形或道具痕迹画入后代。新增的国风、山海、妖怪和巨人角色也走同一条繁衍路径。
- “系列接力”支持本轮五册；巨人动作更沉稳，伞怪有小幅弹跳。可用画材设置中的幅度和节奏调整。
- 首次或没有保存选角的默认舞台采用国风葫芦；明确保存的旧选角保留。

配色和制作规则详见《主题角色设计-v13.md》。样张是实际绘制函数生成的 PNG，并非页面截图。

这是候选版本：原生 Canvas / 逻辑验证与真实浏览器验收分开记录。

- Ctrl+Z 撤销风格应用；场景分享码保留当前画材参数。语言偏好独立于作品分享。

- 默认首页现在以 **7 列 × 6 行** 开场，先让完整群像形成舞台；点击主题、选角或设置中的列数／行数后，可以改成其他构图。

- “邻里回应”把舞台按阅读顺序两两配对：前一位先发出招牌动作，后一位稍后回应；两者之间出现一条短暂的彩色连线，回应方升起泡泡，动作结束后连线、泡泡和姿态一起收束。减少动态效果时连线会关闭，但配对动作仍保留。
- 每次表演都会在动作带右侧显示当前阶段，并在舞台左上角给出一句说明：例如焦点轮演会显示“一个角色先亮相，邻近角色随后回应”，系列接力会提示“系列成员按队列依次登场”。角色周围的短暂标记表示当前正在参与动作，动作完成后自动消失。

# 趣像 · 奇趣物种剧场（files-12 / v12.1.0）

这是在 files-11-grid7x6-42-final 基础上继续推进的版本，更新于 2026-09-22。当前发布候选为 files-12 / v12.1.0；原有 files-7 至 files-11 压缩包保持不变。若已打开同目录 index.html，请刷新页面。

## 这一版先这样玩

1. 点击 **潮间带**，让虾、蟹、章鱼、海马、河豚、水母、鳐鱼、寄居蟹同台。
2. 点击 **各显神通**。动作有预备、主体运动、附肢跟随和回落：虾退身摆尾，螃蟹横移开钳，水母收伞上浮，寄居蟹朝壳内缩。
3. 点击 **头像与混生**，选择 **物种单选** 或 **物种混选**，勾选头像，选择登场数量，再点 **让它们登场**。
4. 混选示例：只勾选虾、蟹、水母，选 12 位，会安排每种 4 位。混选保留独立物种，不会自动混生。
5. 点击 **泡泡接力**，观察各角色按顺序呼应，以及角色间经过的细小泡泡；点击 **邻里回应**，观察两两角色先后打招呼；点击 **潮汐圆舞**，观察错相的弧线运动和回落。
6. 点击 **动画来客**，查看海绵宝宝、派大星、龙猫、煤煤虫，以及葫芦七子、莲火小将、云龙小将的趣像画风版本。
7. 点击 **混生花园**，查看银杏虾、云钳守卫、伞帽章鱼、水母茶壶等。也可以在头像库下方分别选择“主体”和“借来的结构”，让新物种诞生。
8. 在 7×6 群像上依次试 **焦点轮演**、**安静群像**、**系列接力**：先看一个角色被照亮，再看回应扩散，最后看整组角色像一支小型剧团轮番上台。

头像库共 **41 类**：保留原有 15 类人物、动物和奇趣角色，加入 5 类花园／异物角色、8 类潮间带生物、13 类动画来客（其中 7 位组成葫芦七子系列，另有莲火小将、云龙小将）。

单选可生成同一物种的一群不同个体；混选会均衡安排选中的物种。人数支持 1、4、8、12、16、24、32、42、48；如果所选物种多于指定人数，会自动提高到能够容纳所有选择的档位。主动应用选角会替换舞台角色，已收藏的角色仍保存在收藏库中。

混生工作台支持新增的 26 类结构，主体和次要结构不同，形成 **650 种有顺序的组合**。它们已经通过代码与绘制检查；其中六组进行了重点视觉整理，其余组合仍有进一步艺术精修的空间。交换主体与次要结构会改变形象。原有 15 类头像可单选和混选，不进入这个结构混生工作台。

在混生场景按 N 会继续生成混生角色；潮间带、动画来客也各自保持对应生成类别。自定义选角后按 N，仍只生成所选物种。选择结果和画材可随场景分享码保存、恢复及撤销。

## 动作的分寸

在“画材与设置”顶部调节 **动作幅度** 和 **表演节奏**。默认幅度较克制；减少动态效果开启后，会进一步降低位移和摆动，并取消泡泡之间的移动连线。

四种新剧场动效都有有限时长并回到原位。连续点击由既有动作队列处理，不无限叠加位移；泡泡和连线都有数量与寿命限制。短音效沿用作品的声音开关，实际听感仍待真机验证。

`样张/09-各显神通.gif` 是作品真实动作逻辑生成的动画预览，包含 56 帧。它不是浏览器录屏。

## 打开与体验

解压后，用桌面浏览器打开本目录的 `index.html`。作品的绘图和基础交互不需要安装软件或访问在线素材；本版已移除外部字体请求。初次体验推荐以下顺序：

1. 点击 **风里花园**，看银杏叶、仙人掌、菌菇和云组成的小群落。
2. 点击 **送一阵风**，观察叶片倾斜、菌盖轻弹、云团舒展。
3. 点击 **异物茶会**，再送一阵风，留意茶壶盖和壶嘴上方的细线。
4. 点击 **局部风**，让指针经过某几个角色。再点一次或点击横幅中的 Done 退出动作刷。
5. 点击 **画材**，先选择铅笔、木刻或蜡笔，再改变“笔触疏密”；保持疏密不变，再试“颜料浓淡”。
6. 点击 **留下这一刻**，保存当前画布的 PNG。此项输出画布当前分辨率，暂不提供额外的超清倍率。

双击或长按角色可打开原有收藏卡。拖动角色可转动；`?` 打开原有动作帮助。部分原有设置和帮助文字仍为英文。

`Ctrl + Z`（Mac 为 `⌘ + Z`）可撤销角色重生成、主题切换或分享导入，并一起恢复对应的角色、构图和画材。最多保留五次记录。

## 保留的四个主题入口

| 入口 | 作用 |
|---|---|
| 众生图鉴 | 人物、动物、植物、菌菇和奇趣物件共同出现 |
| 风里花园 | 以植物与菌菇为主，带主次关系的小群落 |
| 异物茶会 | 茶壶、云与菌菇，浅色纸面和细线 |

主题会设置一组角色、构图与画材。已经收藏的角色会优先保留，因此你的画面可能与样张不同。要保存完整场景，请在“画材与设置 → Share”复制 scene code。

## 延续的画材与花园功能

- 新增五种具有独立轮廓的角色：银杏叶旅人、仙人掌守望者、菌菇伞客、茶壶梦游者、慢吞吞的云。
- 人物头部增加细长、短宽、上下宽度不同等轮廓变化，不将外貌与性格绑定。
- 增加笔触疏密、颜料浓淡、干湿三项画材参数，配合已有线条粗细使用。
- 铅笔增加疏排线；水彩与水墨增加局部积色、颗粒；木刻、蜡笔、Riso 与波普可改变排线或纹理密度。
- 降低表情附近的排线强度；纸面纹理更轻，留白更清楚。
- 增加有限时长、不同结构各有回应的风，以及可调范围的局部动作刷。
- 新角色进入原有收藏、换色、分享、头像、卡片与群体表演的绘制流程。
- 修复“关闭连锁反应”实际仍使用正常强度的问题。
- 新画材参数可保存与分享；固定种子可重现同尺寸纸纹与颗粒。分享仍不保存动画瞬间。
- 加强分享输入检查，拒绝不完整场景与不认识的角色标记，限制尺寸与画材参数。

## 参数怎么理解

**疏密**改变排线、颗粒等的数量；**浓淡**改变着色强度。二者分别控制。

**干湿**主要影响水彩和水墨的铺色边缘与局部积色，对平涂等材料变化较小。不同材料的参数效果不会完全相同。

**动作刷范围**改变一次影响多少角色，与画材密度无关。

植物与菌菇、茶壶与云的比例在“新的邻居”中设置，影响后续生成。设置后点击 Apply cast now 或按 N。按 8 可继续切换人物、动物、奇趣、花园与异物分类。

## 兼容与验证范围

新版本可读取旧版七段角色基因代码。新角色带扩展形状标记，需用本版本打开；旧版不能正确读取这些新角色。

本版通过语法检查和 44 组应用逻辑／本地 Canvas 绘制检查，并检查了实际绘制函数生成的样张。覆盖新旧角色代码、650 种结构组合、41 类物种单选与混选、保存恢复、撤销、默认 7×6 构图、旧版网格迁移、工具分组、动作尺度与回落、泡泡和连线清理、旧动作、七种群体表演，以及卡片和三种头像绘制。

浏览器工具此前因本地页面安全策略阻止预览，本次没有绕过该限制。因此，浏览器按钮点击、移动端布局、真实音频、实际下载与长时间运行性能仍需真机确认。`样张`是实际绘制函数生成的静态画面，不是浏览器截图。
