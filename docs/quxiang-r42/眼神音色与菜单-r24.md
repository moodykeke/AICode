# r24：眼神的细节、一套音色库、重新设计的设置面板

2026-09-23。

## 一、眼神：头本来就跟着转，眼睛几乎没动

**实测**：鼠标挪到左边→右边，头的 yaw 从 −1.0 变到 +1.0（跟随正常）。问题在**瞳孔**——
各条绘制路径里瞳孔位移只有眼半径的 0.2–0.45 倍，7×6 时约 1–2px，等于看不见；
鼓眼（青蛙/河马那类）更只有 0.03 单位。

修法在**信号层**，不逐行改画法：
1. **放大并饱和**：视线偏一点，瞳孔就走明显一段（×2.4 横 / ×1.9 纵，clamp 在 ±1 内）；
2. **微扫视（saccade）**：每 1.6–3.4 秒极轻动一下瞳孔，避免"死盯"的塑料感；
3. **被按住凝视时多眨一次**：与 r20 的"按住慢下来"联动。

**验收数字**（1×1 主角，脸宽 244px）：指针固定不动、只切放大倍数 0→2.4，
瞳孔质心位移 **29.9px**（纯眼球运动，不含头转）；指针左右移动时整脸质心位移 63px。

## 二、音色库：五件乐器 + 共享混响

原来全应用只有 `tone()`（振荡器+包络），马林巴也只是正弦短衰减。新增一套轻量音色库
（不引外部依赖，保持离线单文件可用），每条都用真实合成手法：

| 音色 | 手法 |
| --- | --- |
| 马林巴 | FM（载波×调制器 3.5 倍，调制指数快落）+ 木槌击打噪声瞬态 |
| 音乐盒 | 非谐泛音簇 1 / 2.01 / 3.02 / 4.7，极快起音 + 长光辉尾 |
| 古琴 | **Karplus-Strong 拨弦**：噪声脉冲进延迟线 + 低通反馈，真拨弦颗粒感 |
| 钟琴 | FM 钟（比率 1.41），长衰减，重送混响 |
| 木鱼 | 带通噪声瞬态 + 短促音高敲击 |

另有共享**混响**（生成脉冲响应的卷积器，1.8s）挂在既有 MASTER 与压缩器总线上；
所有音色仍服从声音开关与音量。**弹奏、乐曲、轻触回应**都改走当前乐器。

**验收指纹**（440Hz 离线渲染，实测）：亮度（过零率）跨度 **881–2563 次/秒**、
衰减跨度 **0.36–1.92 秒**——五件乐器在频谱与包络上都分得开。

设置里新增「音色」选择（马林巴/音乐盒/古琴/钟琴/木鱼），随场景分享码一起走。

## 三、设置面板重新设计

原来 11 个分组平铺（画材/Grid/新的邻居/Cast/Look/Motion/Sound/Autoplay/Share/演奏与界面/动作的分寸），
找一项要滚很久。现在：

- **归成五层**：场景与演员(12) / 画材与风格(10) / 动作与表演(7) / 声音与音乐(3) / 界面与分享(9)；
  音阶调式与音色归入"声音与音乐"，沉浸把手归入"界面与分享"。
- **每组折叠**，展开状态记在本机；首次只展开第一组。
- **顶部搜索框**：输入即筛（空组自动收起并展开命中的组），并显示命中项数。
- 画材预览与提示原本浮在面板顶部，现归入「画材与风格」组内。

## 四、验证

- 眼睛：上述两组像素测量；1×1 特写截图里瞳孔明显偏向指针一侧。

- 面板：五个分组与计数正确；搜索"音色""分享"各命中 1 项；折叠状态跨开关面板保持。
- 全程无控制台错误。
