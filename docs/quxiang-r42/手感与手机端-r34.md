# r34：点击不再自转 + 划动才转头 + 班级可随时切换 + 手机端适配

## 一、如何切换班级（回答你的问题）

**进班之后，表演条（工具）里会多出「换个班…」**，点它就能重选班级；旁边是「退出班级人像」。
实测：进班后工具条 = 加载班级(隐藏) / **换个班(显示)** / **退出(显示)**，点「换个班…」面板正常弹出并列出可选班级。
（角色的区分在登录侧：学生只列自己名下的班；教师列自己带的班 + 全校班级列表。）

## 二、点击/拖动的手感（按你说的改）

**原来为什么会转一圈**：基线 `endDrag` 里，点击（几乎没移动）就 `h.spinning=true; spinVel=±(9~14)`
——一次快速自转；划一下松手还会按甩动速度再转。现在：

| 操作 | 现在的结果 |
| --- | --- |
| 点击头像 | **不自转**；轻弹一下 + 表情 + 声音，**脖子明显伸长**（见下） |
| 点击后左划/右划 | **转头**（拖动中 yaw/pitch 跟随手指，松手停在转到的角度） |
| 快速划动 | 也只转头，**不甩转** |
| 不碰它 | 只是略微跟随视线（原有行为） |

点击的"脖子变长"这次做成**看得见的**：新增**脖子伸展脉冲**——点击后头沿脖子升起约 0.35 个头高
（网格上约 10px，原来只有 2px 的轻弹），约 0.6 秒回落。实测 `__neck.pulses` 点击后立即增长、0.9 秒回落到 0。

**技术坑（记下来了）**：基线是把 `endDrag` **按值**注册进 `pointerup/pointercancel/pointerleave` 的，
覆盖 `endDrag` 这个绑定没用（监听器里存的是旧函数）。最后用**捕获阶段的监听**抢在它前面改这次拖拽的状态
（`moved`、`vel`），才既不改基线逻辑又能改结果。

## 三、手机端适配

在 390×844（触摸）实测后修的：

- **按钮点得准**：工具条按钮原来只有 **42×27px**，现在窄屏下所有按钮（除色块/圆点）统一 **≥40px 高**；
  修复后"矮按钮"统计 **0 个**。
- **不再裁切**：工具条/底部动作行/键位行改为**横向可滑**（原来超出就裁掉，右侧按钮点不到）。
- 顶部工具区窄屏密度收紧；设置面板占满宽度；遮罩与暗房按钮同步抬到可点高度。
- 底部「趣像 · 众生有趣」在窄屏不再被挤成竖排。

## 四、手机端怎么触发"热键"

键盘在手机上没有，所以每个功能都必须有**可点的入口**：

- 表演条（工具）里：大合照 / 看照片 / 班级人像 / 换个班 / 奏一段 / 全场弹一遍 / 换调 / 换一首 …；
- 卡片上的动作按钮：天演、收藏、卡背等；
- **快捷键一览**（底部 `?` 按钮）：整张键位表本身就是可点的动作面板 —— 点任一键帽即触发对应动作，
  新加的大合照（`;`）与看照片（`'`）都在表里。
