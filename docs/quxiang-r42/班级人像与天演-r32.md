# r32：班级人像（真实同学进剧场）+ 天演改名 + 脖子回归修复

2026-09-23。三件事：把平台上的学生头像接进剧场（统一风格、可排班级大合影）、
把「繁殖」改名「天演」、修回被我改坏的"点击跳起 → 脖子跟随"。

## 一、班级人像：真实同学进剧场

- **入口**：表演条「班级人像 → 加载班级人像…」→ 选班（学生读自己的班，教师读带的班）→ 读名单 → 逐张取头像 → 排成**班级人像墙**（`八年级05班 · 52 位`），`;` 直接出**班级大合影**（题字带班级名）。
- **风格一致**：不再由浏览器逐张现抠，而是读**服务端基线** `/avatars/unified/display/<uid>.png`
  （`bin/process-student-avatars.py` 生成：抠蓝底 → 头部锚点归一构图 → 纸面 + 统一色温，256²，369 人）。
  实测：52 人 **1.5 秒**加载完、52/52 全部走基线（浏览器内处理只是兜底，若某张基线缺失才启用）。
- 数据通道：名单 `/api/v1/growth/teacher/classes/{id}/growth-ranking`（含 `avatar_url`）；班级列表见脚本注释。
- **同学的头像不参与天演**：班级模式下点「天演」会被拒绝并提示；
  卡片都带 `__student` 标记，将来若把学生做成台上角色，天演闸门同样认它。

## 二、「繁殖」改名「天演」

- 卡片动作按钮：`⚭ Breed` → `⚭ Evolve`；中文词条 `['繁衍','Breed']` → `['天演','Evolve']`（界面显示「⚭ 天演」）。
- 卡背文案同改：`再次繁衍时…` → `下次天演时…`。

## 三、脖子跟随：修回（这是我 r31 引入的回归）

r31 为了压住"余震抽长脖"，把触发阈值改成了与头身成比例 `max(1.2, s×0.08)`。网格上 s≈28 → 阈值 2.24px，
而一次正常点击跳起的峰值位移只有 **2.06px**（中档）—— 刚好卡在阈值下，于是"脖子不跟了"。
根因本已从源头解决（摆造型期间 feelImpulse 直接不收冲量），阈值该回到 1.2px。
实测（`NECK.marks` 增量）：短 +6 / 中 +8 / 长 +9，关闭跳起时 +0 ✓。

## 四、这轮踩的两个坑

1. **单位不一致把卡片放大 50 倍**：布局里 `s` 是"卡的半高（像素）"，绘制却当成"设计尺寸的倍数"用
   → 52 张卡渲染成一片模糊色带。统一为 `ch = 2s`、`cw = ch × 设计宽高比`。
2. **抠底判据被自己的"蓝色溢出抑制"骗过**：抑制把残留蓝底压成青色（b≈max(r,g)+6），
   而我的检测阈值是"差 > 12"→ 测不出来，误判为已抠净。现在主判据改成"贴近外圈中位色"（任何底色都能对付），
   复检用青判据（`b-r>4 & g>120`）：外圈残留 0 张。
