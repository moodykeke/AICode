# 趣像：从角色实验到完整创作体验

基于本地 files-12 / v12.1.0 候选实现与原生 Canvas 样张的产品审视。

## 当前判断

趣像已经具备独特的角色轮廓、自然物种、结构混生、手绘画材和物种招牌动作。辨识度来自“像在纸面上生活的一群小角色”。接下来应围绕一次可完成、可保存、可重玩的创作体验安排投入。

当前版本已将场景选角与画材风格分开，加入中文／English 主创作界面、八种可直接应用的风格配方和 7×6 舞台编排。同一群角色可以在不同画材之间比较；焦点轮演、安静群像、系列接力把群像从“同时出现”推进到“有主次地观看”。语言是本机偏好，场景分享承载角色与作品设置。

## 建议的推进顺序

| 顺序 | 具体工作 | 达到什么程度才算完成 |
|---|---|---|
| 1. 完成真实操作验收 | 桌面、窄屏、触摸设备；语言切换、两个抽屉、键盘焦点、导入撤销、下载、音频 | 用户能独立完成选角 → 换风格 → 编排 → 保存；关键操作无阻断，减少动态效果有效 |
| 2. 固化版本交接 | 以 `版本记录.md`、`版本信息.json`、`manifest.json` 和新包名记录每次构建 | 其他小组能按清单复现、核对哈希，并在不覆盖旧包的情况下回退 |
| 3. 整理创作入口 | 用“场景、角色、风格、表演、保存”组织界面，将高级画材放入展开区域 | 新用户无需阅读帮助即可开始，当前选择与下一步操作清楚可见 |
| 4. 做六至八组完整艺术主题 | 每组包含配色、物种组合、构图、招牌动作节奏和封面；允许保留角色仅换风格 | 每组有独立视觉性格，小缩略图也能区分；桌面和窄屏构图都成立 |
| 5. 完成作品输出 | 静态图尺寸选择、透明头像、短循环动画导出；保留场景码 | 文件实际下载成功，背景与尺寸正确，动画首尾自然衔接；导出后可恢复继续编辑 |
| 6. 精修混生与角色关系 | 先精选十二组混生；加入注视、让路、接物、害羞回应等两角色动作 | 借来的结构接得自然，缩小后仍可读；互动有起因、回应与结束，主体不会重叠失控 |
| 7. 扩大语言与内容覆盖 | 将旧角色故事、画布卡片、动作帮助和遗留提示迁入统一词条；再评估日语、繁体中文 | 核心路径没有混用文字；长文本不挤压布局；用户自写故事、名字和分享码保持原文 |

## 建议优先制作的完整主题

- **潮间来信**：虾与水母为主角，留出一条海流般的空白，泡泡接力连接视线。
- **青花异物小集**：茶壶、云、菌菇，瓷白工笔配色，动作轻而慢，以壶盖和云团回应。
- **森林夜谈**：龙猫、猫头鹰、菌菇与煤煤虫，以灰绿和暖纸色组织前后层次，偏重呼吸与凝视。
- **蜡笔游园会**：河豚、派大星、仙人掌，用较鲜明的块面和不整齐但平衡的队形，动作带短暂停顿。
- **孔版奇物报**：精选混生，统一限色方向、标签层级和版面节奏，适合做一页可收藏的小报。
- **铅笔观察簿**：单个角色或两位朋友，保留大面积留白，突出轮廓、须毛与目光交流。

这些是后续完整主题的设计建议；files-12 已交付群像编排能力，但尚未将上述六组全部制作为独立场景。

## 艺术判断标准

1. 缩到头像尺寸仍能读出轮廓，不依赖文字说明才认得出来。
2. 同一幅作品有主次、疏密与留白，颜色与动作服务于主体。
3. 物种的动作源于身体：甲壳、软体、叶片、气球感各有不同。
4. 群体表演有等待、回应和收尾，安静时也值得观看。
5. 混生保留一个清楚的主轮廓；附加结构避开表情区，并与身体连接。
6. 画材改变轮廓、肌理和着色规律，风格名称应与实际样张一致。

## 本轮边界

中文与 English 已覆盖主创作操作、选角、八种风格预设、设置分组与标签、编排入口及常用提示。原有故事正文、画布卡片中的身份文案、部分旧动作说明还没有全面本地化。用户输入内容保持原文。

检查使用隔离 JavaScript、DOM 测试替身和原生 Canvas；当前 files-12 为 44/44 通过。真实浏览器操作、手机布局、音频、下载与长期性能仍待验收。下一轮应先补齐这一条闭环，再继续扩大功能面。
