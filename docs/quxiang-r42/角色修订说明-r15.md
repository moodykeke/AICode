# r15：欧洲神话与百鬼小町头像修订

2026-09-22。本轮重绘欧洲九位、日本三位，共十二位。保留原角色编号与收藏编码。

## 为什么重绘

此前将脸部放大，却让头饰保留旧坐标，造成头饰与头部错位；相同的窄眼、实心鼻块与帽子反复组合，让角色趋同。颈部和肩膀各自收尖，又造成零件拼接的观感。

本轮把头部、头发、头饰、颈肩放回同一套坐标，以经典头像的简洁线条为尺度。趣味来自身份与神态，不依赖凸眼、吐舌或放大的鼻块。它们是当代插画化演绎，并非历史服装或神话原貌复原。

## 统一尺度

- 头像承担绝大部分视觉面积，头饰围绕头骨生长；身体只保留低而薄的肩线。
- 颈部为短梯形，先画在后方，再由下颌与领口覆盖，避免悬空与两头细。
- 每位只保留一到两个主要识别符号；轮廓圆缓，角尖、鹿角分叉等关键结构保留方向性。
- 低饱和主色、浅面色、深轮廓构成基本配色。工笔、木刻、水彩沿用同一绘制结构。
- 先看 7×6 小头像，再看单角色放大稿。不能用额外纹理弥补轮廓不清。

## 参考入口与边界

- [The Met：Canova 工作室《美杜莎之首》](https://www.metmuseum.org/art/collection/search/204759)：馆藏说明把蛇发与头像的整体构成联系起来。本轮采用蛇发围住面部的方向，不复制雕塑细节。
- [Seattle Art Museum：《天狗面具》](https://art.seattleartmuseum.org/objects/14520/mask-for-tengu)：馆藏说明确认长鼻人形天狗这一类型。本轮保留长鼻，但主动减弱龇牙、夸张嘴部以适配现有头像系列。

参考页面用于辨认传统特征，作品图像未被下载或打包；本轮图形由项目自身 Canvas 绘制。
