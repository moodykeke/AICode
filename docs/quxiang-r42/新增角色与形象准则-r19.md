# r19：新增角色与形象准则

2026-09-22。本轮回合解决三件事：默认展示改为经典半身像、各系列形象避免单一、新角色与既有系列共用同一套半身版式。
角色编号沿用旧表尾部追加，旧代码与旧编号不变。

## 一、默认与版式

- **默认展示＝经典半身像**：首次打开（或尚无明确选角）时的舞台改为人与动物同台的经典半身像群像，
  纸色 cream、莫兰迪配色；已保存的选角不受影响，点主题仍可随时切换。
- **半身托升级**：`folkBustBase` 由原来的"低肩线托"改为经典半身比例——肩更宽、胸更深、带交领领口与袖缝，
  与经典半身像同版式。此项对国风葫芦、西游行旅、百鬼小町、欧洲神话与巨人同时生效，绘制函数本身不改。
- 画布高度有余量（人物约 3.0 单位／单元格 3.85），肩线下移不会压到下一行。

## 四、绘制约定（供后续加角色）

新角色不再各写一份绘制函数，改为**数据驱动**：`folkAdd(key, name, en, series, kind, col, traits, quirk, look)`，
`look` 描述脸型与配饰：

| 字段 | 取值 |
| --- | --- |
| wide / chin | 脸宽／下颌（数值） |
| hair | hair:topknot｜bun｜twin｜bob｜long｜wild｜crestMane｜bald |
| horns | ox｜goat｜dragon（可配 hornCol / hornEdge） |
| ears | cat｜ox｜long |
| hat / crest | lamp｜basket｜cap｜crown ／ flame｜phoenix｜lotus |
| muzzle / nostrils | 兽吻（位置、宽高、颜色）与鼻孔 |
| brows / thirdEye / beard | 眉、天眼、髯（full｜goatee） |
| prop | fan｜spear｜twinTails｜bib｜glow |
| skin / hairCol / browCol / mouthY… | 肤色与局部覆盖 |

**不可改动项**：`NATURAL` 的顺序即标签索引，新增角色只能追加在末尾，否则旧代码（如 `y1abc!27`）会指错角色。
图鉴目录另在渲染层按系列归并（`curation.js` 末段），不影响标签。

## 五、验证

本轮以**浏览器实测**为主（自动检查套件 verify.cjs 未扩展，仍是 r16 的 54 项）：

- 首屏：默认不再是单一族，经典半身像 15 类同台，7×6 群像成立。
- 逐场景：国风葫芦 7 位、西游 8 位、百鬼 7 位、山海 6 位、动画来客 13 位、经典半身像 15 类、潮间带 8 类、
  欧洲神话 9 位；新增角色逐张开卡特写核对，卡背显示"主体／继承／表达"与真实来源，无控制台错误。
- 链路：新角色可被单选／混选登场、可作繁衍主体或借体（"A child is born." 实测通过），
  编码往返（含 8 字标签）不报错；图鉴分组归并为一段（西游 8／百鬼 7／山海 6，修复了重复分组头）。
- 未验收：真机触控与教室机器长时间运行，与 r17 记录一致。
