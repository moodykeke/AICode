# r39：合影作品化（打印清晰度 + 展板导出）+ 队形按人数自适应

## 一、打印清晰度（设置 →「照片清晰度」：屏幕 / 打印）

拍照时的重绘分辨率随它走：**屏幕版要 ~760px 宽（整幅 ≤600 万像素）**，**打印版要 ~1800px 宽（≤1200 万像素）**，
小屏额外加一道倍率上限（2.2×）以免峰值内存过高。实测同一场景：**屏幕版 1280×230 → 打印版 2560×966**。
打印版下配合「重拍（R）」即可拿到高分辨率成片；设置随场景分享码一起走。

## 二、展板导出（暗房「存展板 / P」）

把合影排成一张**立幅海报**（≈A 系列 **1:1.414**）：顶部班级名 + 日期「· 合影留念」→ 中间合影（带相纸投影与细框）
→ 底部「趣像 · 拾趣馆」+ 朱印。导出 JPEG（打印用，比 PNG 小得多）。实测 **2294×3244**、比例 1.414 ✓。

## 三、队形按人数自适应（这轮发现的真问题）

**现象**：52 人排**弧线**队形时，卡片按"十几个人"的尺寸排，彼此几乎完全重叠 —— 舞台上是一扇"纸条"，
合影与展板都跟着花。（网格队形有按格缩放，所以一直正常，问题只在四个"合影队形"里。）

**修法**：四种队形（三排/一字/弧线/拥簇）的卡片尺寸改为**按人数与可用跨度夹取**，并留 20% 重叠余量
（真实合影也是肩并肩压一点）。实测：三排队形现在就是一张标准的班级合影（3 行 × 17-18 人、每人带名牌）。

## 四、快门吸附（顺带）

缓动是逐帧的：慢设备/低帧率下 1.25 秒还走不完队形，直接拍会拍到"半途的队形"（无头环境 10fps 实测明显）。
现在**快门时刻把卡片吸附到目标位**再抓帧，只影响收尾那一帧。
