# r40：课堂大屏模式（投屏用，全程不需要键盘）

场景：教室里把趣像投到大屏；家长会展示班级合影。要的是"远看好看、近点不慌"。

## 入口与退出

- 表演条 →「课堂大屏」→「大屏模式」；**Esc 退出**（退出时移除按钮排、退全屏、恢复工具条）。
- 没载入班级时会拦下并提示「先载入班级人像，再进大屏模式」。

## 大屏里的界面

- **全屏**（浏览器允许就真全屏；不允许也照常工作）；**收起工具条/页脚**，只留底部一排大按钮；
- 大按钮：**拍合影**（朱印红，最显眼）、**原始 / 喜 / 怒 / 哀 / 乐**（当前态高亮）、**轮播：开/停**、**退出大屏**；
- 尺寸：桌面 **≥64px 高**、92px 宽；窄屏 ≥56px 高（投影与触屏都点得准）。

## 表情轮播（12 秒一换）

原始 → 喜 → 怒 → 哀 → 乐 循环，可随时暂停；换表情是**静默重取**（不弹载入进度），
逐张替换卡画布，内存与首屏一致（旧画布当场释放）。

## 与既有功能的关系

只做"呈现层"：班级人像的载入/切班/点卡片详情仍由班级人像那套负责；大屏模式只管投屏时的界面与节奏。
因此它天然继承：手机可点（按钮更大）、资产版本 `?v=`、双网直出、情绪件缺件退基线。
