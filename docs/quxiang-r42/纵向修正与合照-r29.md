# r29：纵向视线修正 · 点击跳起可配置 · 大合照

2026-09-23。三件事，前两件来自你的指正，第三件是新功能。

## 一、纵向视线方向（原来的确是反的）

**先判定再改**。做法：把瞳孔视线设成 0、只给 `pitch` ±0.5 各渲染一张——正 pitch 那张五官整体上移、
下巴区拉长，读作"头后仰、在看上面"；负 pitch 则额头一大片，读作低头。**即正 pitch ＝ 抬头**。
而指针在角色**下方**时算出的 pitch 是正的（实测 +0.396）→ 头反而抬起 ⇒ 与直觉相反，你的判断正确。

三处输入通道都翻回来（只翻输入，不动既有动作自带的 pitch）：

| 通道 | 改前 | 改后 |
| --- | --- | --- |
| 指针在上 | pitch −0.318（低头） | **+0.319（抬头）** |
| 指针在下 | pitch +0.396（抬头） | **−0.396（低头）** |
| 向下拖动 | pitch 递增（抬头） | **递减（低头）**，且不再顶到 +0.5 的限位 |

## 二、点击跳起：可开可关、高度可调

设置 → 动作与表演 → **点击跳起（开/关）**、**跳起高度（短/中/长）**：

| 高度 | 弹跳初速 | 头顶最高位移（实测） |
| --- | --- | --- |
| 短 | −1.12 | 0.077（约 3px @ 网格） |
| 中（默认） | −1.90 | 0.13 |
| 长 | −2.91 | 0.199 |

**脖子跟随的长度本来就由"头被顶起多高"决定**，所以调高＝脖子伸得更长；关掉后点角色只眨眼/微笑/发声，不再弹跳。
两项都随设置保存并进场景分享码。

## 三、大合照（新功能）

按 `~`（或表演条 → 合影 → 大合照）：**全班随机聚拢到中央摆造型 → 闪光灯一亮 → 出一张照片**。

- **随机样式**（也可在设置里指定）：三排合影 / 一字排开 / 圆弧长队 / 拥簇中央；
- **随机大小**：前排大、后排小，再带 ±12% 抖动与小角度歪头（每张照片用同一个随机序列，形状自洽）；
- **合成本身**：按队形裁切（含 9%/12% 余量），只框住这一群人；
- **导出**：`存照片`（相框三选一：白框题字 / 胶片齿孔 / 宝丽来）与 `存原图`；
- **成片留存**：按下快门那一刻就把这一帧留住——即使队伍已经散开，之后导出仍是同一张合影；
- 拍完自动散场回到网格；`Esc` 可中断。

## 四、过程中的三个修正

1. 第一次实现把 `h.s` 当成了格子尺寸，头被放大 5 倍（网格里 s≈44，我给了 227）→ 改以"当前头的 s"为基准；
2. 闪光在合成之前打开，成片被洗白 → 改为**先出片、再闪光**；
3. 拥簇样式的外圈尺寸公式会算到接近 0，出现一圈"小芝麻" → 限幅（最多三圈、最小 0.66 倍）。
