## 一、投放进化 · 生态缸 —— 见《投放进化-生态缸-r44.md》

- 舞台变成生态缸：点空格投放十五种始祖（或随机开局），每 2.6 秒一代；相邻的配对繁衍（七基因座逐个遗传 + 突变），孤单的克隆；老、挤、不适应的死去。
- 五种气候（温和 / 雪原 / 沙漠 / 夜林 / 海边），选择压力全部来自看得见的特征（毛色、毛量、耳朵、眼睛、蛙皮、胡须、喙、铁皮）；不适应的发抖、冒汗、眯眼。
- 解压工具：拖动撒食物、点哪砸哪的陨石（炸飞 + 辐射突变 + 弹坑）。
- 变种按"哪个部件来自谁"自动命名（灰·兔耳猫、鸮眼尖吻人、毛线帽狐）；物种志记录新种、称霸、灭绝、换气候；种群曲线与排行。
- 入口：表演条"更多动作 → 玩法"、键位表"趣味"一排 ❦；键：空格暂停、1–5 气候、Esc 退出。退出后进化出的生物留在舞台。
