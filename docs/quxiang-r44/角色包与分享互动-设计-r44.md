## 一、角色包

### 1. 现状

角色来源有五六条路：上游经典基因（人物、十二种动物、机器人、外星访客）、`studio.js` 的自然角色（NATURAL）、
`folklore.js` / `new-faces.js` 的 `folkAdd`、`myth-faces.js`、`atlas.js` 的海洋系列、`class-faces.js` 的班级人像。
每条路自己登记名字、配色、特征、画法，场景（`ATLAS_SCENES`）再按名单挑人。结果是：

- 加一位角色要改三四处（登记、画法、场景名单、有时还有借体标志）；
- "一个系列"没有实体：不能整包开关、不能按包统计、不能给包写介绍、不能按包分享；
- 生态缸只能用经典基因——神话角色是"整张画"，没有七个基因座可以拆。

### 2. 角色包的形态

```js
QX_PACKS.register({
  id: 'journey',                       // 稳定 id，进分享码
  zh: '西游行旅', en: 'Journey to the West',
  blurb: { zh: '取经路上的妖与仙。', en: 'Demons and immortals on the pilgrim road.' },
  cover: 'west_monkey',                // 封面角色
  members: ['west_monkey', 'west_pig', 'west_monk', 'west_sandy', 'west_bull', 'west_fan', …],
  tags: ['myth', 'china'],
  scene: { grid: [7, 5], paper: 'rice', style: 'gongbi' },   // 整包上台时的默认舞台
  evolve: {                            // 可选：进生态缸时怎么参与
    genes: 'donor',                    // 'donor'：以借体标志的方式把招牌部件传给后代；'none'：只能整只投放、不参与繁衍
    climate: { desert: .2, snow: -.1 } // 这一包在各气候的底子
  },
  sounds: { enter: 'gong' }
});
```

- **成员仍用现有的登记函数画**（`folkAdd`、`NATURAL_INFO`…），包只是"名单 + 元数据"，不重画、不搬代码。
- 场景菜单、"＋ 角色"面板、生态缸托盘、合影相框题字都从 `QX_PACKS` 生成。
- `build.cjs --verify` 增加：成员都能画、每位都有中英名和两条以上特征、封面存在、id 不重复。

### 3. 首批包（全部来自现有角色，不新增画法）

| 包 | 成员 | 生态缸里的角色 |
| --- | --- | --- |
| 经典头像 | 人物 + 十二种动物 + 机器人 + 外星访客 | 七基因座全开，**进化的主角** |
| 西游行旅 | 师徒四人 + 牛魔、铁扇、红孩儿… | 借体：猴毛、猪耳、僧帽等招牌部件以"标志"传下去 |
| 山海异兽 | 白泽、烛龙、凤凰… | 借体：角、火、翎 |
| 欧洲与希腊神话 | 美杜莎、牛头人、女武神、树精… | 借体：蛇发、牛角、羽盔、橡枝 |
| 日本妖怪 | 座敷童子、猫又、提灯… | 借体 |
| 海洋小剧场 | 虾、蟹、章鱼、水母… | 只在"海边"气候可投放 |
| 我们班 | 班级人像 | 不进生态缸（学生头像不做混血） |

### 4. 为什么"借体"是神话角色进缸的正确方式

神话角色是整张构图，拆不成七个基因座；但 r43 已经做了**借体标志**（新角色当父母时，孩子带上它的招牌，卡背写"借来：蛇发"）。
生态缸里只要把借体当作第八个基因座：孩子以 50% 继承父母任一方的借体，突变可以丢失它。于是可以看到
"美杜莎的蛇发在雪原上三代就没了，在夜林里却传遍全缸"——神话角色成了**性状的来源**，而不是整只混进去变成怪图。

## 二、生态缸再往前几步（"孢子"方向）

按玩家感受排序，每一步都只用现有画法：

| 期 | 玩法 | 一句话 |
| --- | --- | --- |
| E1 | **进化树** | 物种志旁边一张树：每个变种一个小头像，连线到它的父母变种；灭绝的变灰。点节点开卡片 |
| E1 | **成就与图鉴** | "第一只三物种混血""在沙漠活过 20 代""陨石后三代内出现新物种"…；图鉴里收集见过的变种（本机保存） |
| E2 | **地形** | 舞台左右分气候（半边雪原半边沙漠），中间一列是"迁徙带"——看同一个祖先分化成两支 |
| E2 | **捕食与共生** | 狐狸身边的老鼠死亡率上升、熊猫身边的竹子（食物）自己长……只做三四条，讲得清楚的关系 |
| E2 | **天灾菜单** | 陨石之外：冰河期（全缸三代雪原）、洪水（下两排清空）、彗星（全缸突变率 ×3 一代）——都是解压按钮 |
| E3 | **挑战关** | "用三只小鸡开局，在夜林里进化出一种大眼睛生物""20 代内让机器人灭绝"；每关有一句话目标和星级 |
| E3 | **时间倒带** | 拖动种群曲线回到任一代，从那里分叉重来 |

不做的：数值养成、体力、付费加速——生态缸是"丢进去看它自己长"，不是经营游戏。

## 三、分享与互动

### 1. 分享什么（从轻到重）

| 形式 | 内容 | 实现要点 |
| --- | --- | --- |
| 单只卡片 | 已有：卡片图、分享码 `dna@look`。r44 起卡片带中文名与出生证明 | 出生证明目前只存在本机（`cardBio`），分享码里不带；E1 把"代数·气候·父母变种名"压成短尾巴（约 12 字符）附在码后 |
| **缸码** | 一行字复现整缸的起点：`气候 + 种子 + 始祖列表`，对方打开是**同一个开局**，但之后各自演化 | 模拟用可播种的随机数（现在用 `Math.random`，E1 换 `mulberry32(缸种子)`），同一缸码 + 同样操作 = 同样结果 |
| **进化史海报** | 一张竖图：顶部缸名与代数，中间种群曲线，下面"本缸之最"（最多、最怪、最长寿、最短命），底部三条物种志金句 | 复用合影暗房的出图管线与相框 |
| 进化延时 | 10 秒小视频：一代一帧的缩略舞台 + 曲线生长 | 复用"转台动画"的录制管线 |

### 2. 互动

- **展墙**（已有 `wall-submit.js`）：新增"进化史海报"类别；墙上按"最怪的变种""最长的进化史"排。
- **挑战码**：把 E3 的挑战关做成可分享的码，"我用三只小鸡在夜林进化出了猫头鹰眼，你呢？"
- **双人缸**（远期，需要服务端）：两个人各管一半舞台，中间迁徙带交换个体；只同步"迁徙事件"，不同步逐帧。
- 班级场景：老师出一个挑战码，全班各自演化，最后把海报贴到展墙比较——**不涉及学生头像**。

### 3. 边界

- 生物全部是画出来的虚构角色；班级人像（学生头像）不进生态缸、不做混血。
- 分享码只含基因与少量元数据，不含设备或个人信息。
- 展墙沿用现有审核与撤下流程。
