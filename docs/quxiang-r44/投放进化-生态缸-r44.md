# r44：投放进化 · 生态缸

2026-09-24。回答"以前有孢子游戏，是否可以开启投放进化"：可以，而且不用新增任何画法——趣像的每个角色本来就是七个基因座
（头、耳、眼、口鼻、毛发、花纹、打扮）拼出来的，繁衍（`crossDNA`）和突变（`randSeed`）也早就有。缺的是**时间**和**环境**。
生态缸把这两样补上：舞台变成一只缸，一代一代地过，气候决定谁活下来。

实现：`趣像/evolve-r44.js`（构建顺序最后）。样张：`样张/34-投放进化生态缸.png`、`样张/35-生态缸-手机.png`。

## 一、怎么玩

入口：表演条"更多动作 → 玩法 → 投放进化"，或键位表"趣味"一排的 ❦ 键帽（手机动作面板同一排）。再点一次或按 Esc 退出。

| 操作 | 效果 |
| --- | --- |
| **投放**（默认工具） | 点空格子，从天上掉下一只生物（落地有灰尘和"咚"）；托盘里选物种，或选"随机"。按住拖过空格子可以连续投 |
| **随机开局** | 随机四种始祖，每种投一对 |
| **喂食** | 在舞台上拖动撒种子；下一代身边一格内有食物的会吃一颗（嚼嘴），多生、少死 |
| **陨石** | 点哪砸哪：火流星划过、落地闪光、震屏、碎石四溅；半径约 1.25 格内的生物被炸飞（头飞走、旋转、晕），附近 2.2 格的受辐射——它们下一个孩子 60% 会突变。弹坑留 4 代 |
| **气候** | 温和 / 雪原 / 沙漠 / 夜林 / 海边（键 1–5）；舞台叠一层天气：雪花与积雪、烈日与热浪、夜色星月与萤火、海浪与气泡、草地 |
| **速度** | 暂停（空格）/ 1× / 3×；1× 每 2.6 秒一代 |
| **点生物** | 打开它的卡片：可收藏、导出、复制分享码（原有功能）；卡上写着它的"出生证明" |
| **合影** | `;` 照常拍——只拍缸里活着的，等于整缸的全家福 |

缸开着时，会整缸换脸的键（N 新面孔、T 交换、V 消失、6–0、−/=、Ctrl+Z）不响应；其余单人动作照常（让缸里的生物打喷嚏、唱歌都可以）。
空格子不接任何动作、不画任何东西；退出时空格子重新长出新面孔，**进化出来的生物留在舞台上**。

## 二、一代里发生什么

```
吃   ：身边一格内有食物 → 吃一颗（fed）
死   ：p = 3% + max(0, 1.05 − 适应度)×38% + 拥挤(邻居 ≥6: 10%, ≥7: 22%) + 衰老(超寿: 45%) − 吃饱 10%
       寿命 = 4 + 4×适应度 + 物种寿命修正（代）
生   ：p = 16% + 30%×适应度 + 物种繁殖修正 + 吃饱 35%
       要有空的相邻格；有成年邻居 → 与它交配（七个基因座逐个随父或随母，8% 自带突变）
       没有 → 克隆，28% 突变；受过辐射 +60%；外星访客 ×3
突变 ：随机一个基因座换成随机种子（12% 落在"头"上——整只换了物种；其余是换耳朵、眼睛、嘴、毛……）
```

选择压力全部来自**看得见的特征**，所以玩家能看出"为什么是它们活下来"：

| 气候 | 占优 | 吃亏 |
| --- | --- | --- |
| 雪原 | 毛色浅（雪里不显眼）、毛厚（蓬毛、头发、胡子、羽毛） | 长耳朵（冻）、蛙皮（结冰） |
| 沙漠 | 大耳朵（散热）、短毛、沙色、吐舌头 | 厚毛、蛙皮（干裂） |
| 夜林 | 大眼睛（猫头鹰、外星、大眼珠）、深色、胡须、触角 | 浅色、机器人的屏幕眼（反光） |
| 海边 | 蛙皮、胡须（感知水流）、喙（啄鱼） | 厚毛（湿了沉）、机器人（生锈） |
| 温和 | 大家差不多；混血略占优（杂种优势） | 机器人要保养 |

物种还有各自的"生活史"：兔、鼠、鸡、蛙生得快活得短；熊、熊猫、人类生得慢活得长；**机器人不能自己克隆**，得借别人的零件；
**外星访客突变率三倍**。于是不同开局会走出完全不同的故事。

适应度也写在脸上：不适应的会发抖（雪原）、冒汗张嘴喘（沙漠）、眯眼乱看（夜林）、晕乎乎地喘（海边）；很适应的会笑。

## 三、名字与物种志

**变种名**按基因座来自谁生成，所以看名字就知道长了什么：

- 纯种：`毛色·物种`，如"白·兔子""橘·猫""人类"；
- 混血：`毛色·部件部件物种`，最多两个外来部件，如"灰·兔耳猫""鸮眼尖吻人""猪鼻机器人""毛线帽狐"（狐狸长了人的毛线帽）。

**物种志**（面板下方）自动记事，每条带代数：

- 新变种：`老虎和机器人生下了第一只螺栓屏幕眼虎。` / `一次突变：黑耳虎须机器人的孩子头长成了外星访客的样子——绿·虎耳屏幕眼星人诞生了。`
- 站稳脚跟（≥6 只）：`金·鸮眼尖吻鸡在雪原站稳了脚跟（7 只）：毛色浅，雪地里不显眼。`
- 霸主易位：`棕·小狗成了缸里最多的生物（5 只）。`
- 灭绝（曾经 ≥3 只）：`金·小鸡灭绝了（浅色在夜里太显眼）。它们最后一只死前还在数云。`
- 换气候：`气候变成了沙漠。橘·兔牙狐最自在（大耳朵散热快），金·人鼻鸡热得冒汗（小耳朵散不了热）。`
- 陨石、里程碑（第 10/30/60/100/200 代）、缸空了。

面板还有**种群曲线**（前五名各一条色带叠起来，其余灰色，最近 80 代）和**排行**。中英文全部双份写好，跟随界面语言。

## 四、卡片上的文字（`card-words-r44.js`）

顺带补上一个老缺口：经典角色（人物、猫狗、机器人、外星访客及混血）的卡片在中文界面一直是英文
（"Little Oona Dimmock-Orchard · brown rabbit · One gold earring, buck teeth… Naps with one eye open. Afraid of Mondays in March."）。
现在中文界面下：

| 项 | 例 |
| --- | --- |
| 名字（按基因哈希，和英文名一样稳定） | 郑点点、老阿宝、毛毛大王、咕噜教授、汪可乐、型号 42 · 布丁；混血用两个名字：乖阿宝-朵朵 |
| 物种 | 灰猫、琥珀色的老虎、田鼠、仓鸮、大熊猫；混血：大熊猫 × 猫头鹰 × 机器人 混血 |
| 特征 | 猫头鹰的耳朵、鼻子和嘴、机器人的眼睛、圆眼镜。 |
| 爱好与害怕（与英文同一索引） | 天天练大提琴，拉得很烂。怕表格。／ 对茶匙很有意见。怕三月的星期一。 |
| 缸里出生的生物 | 第 7 代 · 温和 · 父母：熊猫 × 棕·猫头鹰 · 突变 |

英文界面不变；神话、民间、系列角色保留各自的中文设定。其他扩展也可以用 `cardBio(dna, {zh, en})` 给某段基因登记卡片文字（上限 400 条）。

## 五、性能

- 模拟每代只做一次 O(格数×邻居) 的计算（35 格 ≈ 300 次适应度估算），不在逐帧里跑。
- 天气层是几十个小图元 + 一次整屏叠色；4 倍 CPU 降速下（1280×800，headless 无 GPU）：
  普通舞台每帧 94ms；缸里 13 只 + 雪原 39ms；夜林（整屏正片叠底）52ms。空格子不画，所以缸越空越快。
- 物种志最多 60 条、曲线 80 代、卡片文字 400 条，内存可忽略（全程 JS 堆 9.5MB）。

## 六、调试出口

`window.__evo.state`（代数、气候、活着的只数、变种数、食物数、最近物种志），`__evo.enter()/exit()`、`__evo.drop(格号, 物种)`、
`__evo.gen(n)`（立即过 n 代）、`__evo.climate('snow')`、`__evo.meteor(x, y)`、`__evo.random()`、`__evo.speed(0|1|3)`、`__evo.tool('drop'|'food'|'meteor')`。
