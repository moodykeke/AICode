# r45：界面第一期（P1）与角色包登记表

2026-09-24。落地《界面与键位-高观点改造方案-r43》的 P1 与《角色包与分享互动-设计-r44》第一节。
实现：`趣像/ui-r45.js`、`趣像/packs-r45.js`。样张：`样张/39-界面P1与角色包.png`、`样张/40-手机底部五键.png`。

## 一、角色包登记表 `QX_PACKS`（`packs-r45.js`）

```js
QX_PACKS.register({ id, zh, en, blurb:{zh,en}, cover, members:[…], tags:[…], evolve:{ genes:'full'|'donor', climate:{ snow:.2, … } } });
QX_PACKS.list / byId[id] / packOf(key) / dna(key, seed) / name(key, en) / short(key) / audit()
```

- 包只是"名单 + 元数据"，成员仍用原来的登记（上游经典基因、`NATURAL_INFO`、`folkRegister`/`folkAdd`、atlas 的海洋与动画来客）画，没有搬代码。
- 首批 9 包全部由现有登记自动生成：经典头像 15、国风葫芦 7、西游行旅 8、山海异兽 6、百鬼小町 7、欧洲神话人物 9、花园与异物 5、潮间带 8、动画来客 13。
- `audit()`：封面在名单里、中英名齐全、每位成员能生成 DNA、有中文名、有两条以上特征。当前 0 问题。
- **角色包浏览器**（表演条"更多动作 → 角色包"、手机底栏"角色"）：每包封面、介绍、成员名单与"整包上台"。
  有专属场景的包（五个民间系列、潮间带、动画来客、花园、经典）走各自的场景设定（纸色、画风、密度），其余轮流填满舞台。
- 生态缸托盘、生态缸的神话适应度都从这里取。

## 二、上下文层 `QX_CTX`（`ui-r45.js`）

- 弹层（角色包、进化树、图鉴与成就、挑战）开着时，**按键只交给最上层**：以前在弹层里按字母键会穿透到舞台（按 S，背后全场打喷嚏）。
- **Esc 永远只退一层**：以前在生态缸的进化树里按 Esc 会直接退出生态缸；现在第一下关树、第二下才出缸。
- 按钮自身的回车、空格、Tab 默认行为不受影响。新弹层用 `QX_CTX.add(id)` 登记。

## 三、键位登记 `QX_KEYS`

把基线 `KEYMAP`/`KEYINFO`（74 条）与各扩展自己挂的监听（Tab、`< > |`、暗房的 R 与 1–7、生态缸的空格与 1–5、Esc）汇成一张表：
`__keys.list()` 列出（键、上下文、来源、中英文名），`__keys.audit()` 查同一上下文的重复登记与缺中文名的键（当前 0 问题），`__keys.ctx` 显示当前最上层。
键位表与手机动作面板仍由 `KBROWS` 生成；下一步是把扩展的自挂监听迁到登记表里统一分发（P2）。

## 四、工具栏浮层化

- 顶栏与表演条收进 `#toolDeck`，**浮在舞台上方**：展开/收起不再改变舞台尺寸。实测舞台高度 740 → 740px、每张脸大小与位置不变（r43 时是 706 → 611px、脸 73 → 64px 并整体下移）。
- 半透明底 + 模糊；有鼠标的设备上空闲 6 秒自动淡到 12%，指针移到上方 64px 内、停在上面、焦点在里面或按 Tab 时复原。
- 代价：展开时顶上一排脸会被盖住一部分（这是浮层的本意——要看全场就收起）。

## 五、手机底部五键

≤640px 宽时，原底栏收起，底部固定五个大按钮（每个 ≥48px 高）：

| 键 | 做什么 |
| --- | --- |
| ✦ 演 | 打开动作面板（r43 的分区键位面板，带名字） |
| ◉ 拍 | 大合照 |
| ▦ 角色 | 角色包浏览器 |
| ❦ 进化 | 生态缸（进缸后底栏让位给生态缸面板） |
| ⚙ 设置 | 设置面板 |

舞台下沿让出底栏高度（390×844：底栏 58px，舞台底边 786px），不会被遮住。
